九州鐵道漫遊攻略：用 JR Kyushu Pass 探索日本西南門戶

訪問九州的旅客經常誤會有所謂「福岡JR Pass」，但，事實上JR九州在福岡地區提供的票券名稱是「JR Kyushu Pass」（JR九州鐵路周遊券）。這個名稱上的差異很重要——它不僅是一張交通票券，而是串聯整個九州六十七個車站的彈性移動工具。本文將從鐵道旅行的角度，分享如何用這張周遊券玩出不同於一般觀光客的路線。

▌JR Kyushu Pass 的核心優勢

與其把它想成一張「省錢卡」，不如理解為「九州深度探索通行證」。JR Kyushu Pass 分為三種版本：覆蓋全九州的「全九州版」、以北九州為主的「北九州版」，以及以南九州為主的「南九州版」。票券效期分別為三日或五日，對應不同的行程天數規劃。

為什麼強調「鐵道」而非「自駕」？九州的高速軸線其實是鐵道——鹿兒島準快車往返博多的班次密集，從鹿兒島中央車站到博多的直通列車最快只需約一小時二十分，比租車更適合時間有限的旅客。且沿線停靠的中小站（如久留米、大牟田）往往距離著名景點更近，省去停車麻煩。

▌推薦路線與目的地

🔹路線一：「溫泉鐵道」——從博多直達由布院

由布院的魅力不在於「景點」，而是它在九州鐵道網路中的特殊地位——由布院車站是少數以觀光小鎮命名的車站，周邊溫泉設施達兩百家以上。乘坐JR久大線從博多出發，沿途會穿過久留米的平原，車程約兩小時。使用北九州版或全九州版周遊券，這段交通費含在票內。

當地特色： 由布院的「湯之坪街道」聚集了十一間人氣甜品店，其中「Milch」的半熟起司蛋糕和「大分佈甸」是排隊名物，但真正懂吃的旅客會去車站旁的「由布院站前的 cafe SAIKO」，一份套餐約莫一千日幣左右，cp值高出平均值不少。唯一缺點是，淡季（11月至12月）的傍晚五點後街道人流驟減，若計畫當日往返需注意末班車時間。

🔹路線二：「火山物語」——鹿兒島桜島一日往返

鹿兒島市的 JR 站（鹿兒島中央站）是九州南部的樞紐，從博多人偶爾會選擇搭乘高速巴士，但鐵道其實更值得推薦——乘坐JR鹿兒島線快速列車約一小時十五分可達。桜島的渡輪口就在鹿兒島水族館附近，持周遊券可免費乘船。

當地特色： 桜島的「溶岩海岸步道」是一條沿海的自然步道單程約四十分鐘，天氣好時可以看到對岸霧島的火山稜線。推薦在「桜島港」搭乘十點的渡輪，午餐時間剛好可以在対岸的「天文館」吃一碗鹿兒島特有的豚拉麵——與博多拉麵不同，鹿兒島豚骨的湯頭偏清爽，配上細麵和黑胡椒，是只有在地才吃得到的口味。一碗約莫八百五十日幣。

🔹路線三：「港都物語」——門司港與懷舊街區

門司港是九州的最北端，從博多乘坐JR山陽線約一小時可達，這裡保留了明治到大正年間的洋館建築群。港口周邊的「藍翼吊橋」是九州現存最老的海上行人吊橋，門票兩百日幣，持周遊券可無限次進出。

當地特色： 門司的港都氛圍與博多的都會感形成強烈對比——這裡更像「縮小版的神戶」。推薦走一趟「關門隧道」步道，全長七百八十公尺，穿過海底連線本州與九州，走完全程約十五分鐘，是鐵道迷口中「九州最值得炫耀的 underrated 體驗」。走完後，附近的「門司港Retro」有十多家老咖啡店，其中「榮螺塔」的咖啡約五百日幣，是少數結合歷史建築的高cp值歇腳點。

🔹路線四（進階）：「雙縣跨越」——從鹿兒島到霧島溫泉

如果持有全九州版周遊券，另一條值得推薦的是「鹿兒島中央→霧島」區間。霧島的溫泉鄉分散在五個地區，其中「霧島溫泉鄉」是最成熟的遊溫泉區，從JR霧島站乘巴士約二十分。持周遊券可無限次乘坐區間的普通列車，省下每次單程買票的麻煩。

▌實用資訊

💰票價資訊：

JR Kyushu Pass 目前分為三種版本。北九州版（三日）成人票約，莫略低於全九州版的七成；全九州版三日票與五日票的價差約在一千五百日幣左右。可在JR九州旅行社（博多站內有服務視窗）或出發前十天透過 KKday 購票，海外票價通常比當地購買略高。

🕐營業與兌換：

JR九州鐵路周遊券的兌換視窗位於博多、小倉、久留米、熊本、鹿兒島中央、佐世保等九個主要站的綠色視窗。建議首日抵達博多站後先兌換，避免排隊等候影響後續行程。服務時間generally為早上七點至晚上八點。

✈️交通銜接：

福岡機場（國內線 Terminal 和國際線 Terminal 之間有巴士接駁，約十五分）到博多站可搭乘地下鐵機場線，直通約五分。如果從關西機場進入，可搭乘 JR 高速船（ 神戶/大阪）但轉乘時間較長，從關西機場到博多的 total time 超過四小時建議直接飛福岡更為便捷。

▌旅遊小提示

第一，「不用把行程排滿」。JR Kyushu Pass 的價值不在於「跑最多點」，而在於「隨時可以改變路線」。例如由布院天候不佳時臨時改轉久留米吃拉麵，或從鹿爾亞臨時加碼去阿蘇火山——這些彈性才是票券的核心價值。

第二，「善用普通車」。周遊券涵蓋全區間的普通車，即使指定席已滿也不影響行程。日本鐵道的普通車常有意外驚喜——例如從博多是濱海岸線的普通車上看到的夕陽，比任何付費景色更值得。

第三，「辨識人潮低谷」。週三至週五是九州鐵道的相對淡季，週末則集中前往熱門溫泉區。如果時間可，建議避開週六的由布院車站，人潮差不只三倍。

九州的面積約為本州一個中型縣的大小，鐵道網路卻異常發達。JR Kyushu Pass 不只是一張票，更是一把開啟這個多元地域的鑰匙——無論是火山、溫泉，還是港都的歷史，都能在列車的行進間逐一展開。
