金澤 JR Pass 攻略：把金澤當作北陸中繼站，通票才真正划算

2026-08-11 1522 字
金澤交通 JR Pass 北陸自由行

簡介

金澤沒有名為「Kanazawa JR Pass」的城市專屬通票。對旅客真正有用的，是全國版 Japan Rail Pass 或涵蓋北陸的新幹線區域通票。判斷是否購買的關鍵，不是金澤景點數量，而是行程有沒有串聯東京、富山、福井、敦賀或關西。

從東京乘北陸新幹線前往金澤約2.5小時，適合把金澤安排成兩至三晚的中繼站。不過，兼六園、近江町市場與茶屋街集中於市中心，主要依靠巴士及步行，JR 通票通常不能包辦市內交通。若只往返金澤站與景點，單買車票或使用當地巴士乘車券往往更直接；若每天跨城市移動，通票的價值才會浮現。

特色亮點

金澤的優勢是「大交通靠 JR、市內觀光靠巴士」。北陸新幹線適合連線東京、富山與福井方向，普通及特急列車則可延伸至加賀溫泉、敦賀等地。購買前應把預定乘坐的指定席逐段試算，再與通票當期售價比較；JR Pass 價格及適用列車可能調整，不宜只憑舊攻略決定。

這種安排特別適合首次探索北陸、又不想每天更換酒店的旅客：以金澤為基地，分別安排市內文化日、富山或福井一日遊。若全程只留在金澤，通票多半無法回本。

推薦地點

1. 兼六園

日本代表性庭園之一，曲水、石橋、茶屋與季節植栽被壓縮在可步行的範圍內。冬季雪吊是金澤最具辨識度的景觀，春季賞櫻及秋季紅葉則較擁擠。地址：〒920-0936 石川県金沢市兼六町1。成人入園約¥320，開園時間通常為7:00至18:00，冬季縮短至8:00至17:00。

2. 金澤城公園

與兼六園隔橋相連，適合排在同一個半日。石川門、五十間長屋與不同年代的石垣，能看出城郭經歷火災及重建後留下的層次。地址：〒920-0937 石川県金沢市丸の內1-1。公園基本區域免費，部分復原建築另行收費；一般開放時間約7:00至18:00，冬季約8:00至17:00。

3. 金澤21世紀美術館

這裡不是傳統收藏型美術館，而是以圓形建築、公共空間及當代裝置吸引旅客。免費交流區適合短停，熱門展覽則可能需要預約或排隊。地址：〒920-8509 石川県金沢市広坂1-2-1。交流區免費，展覽票價依內容而異；展覽區通常10:00至18:00，週五、週六延長，週一多為休館日。

4. 近江町市場

從海鮮丼到加賀蔬菜都集中在市場內，但名店午餐時段排隊明顯，價格也比一般食堂高。我的建議是上午抵達，先比較份量與標價，再決定是否吃海鮮丼；想控制預算，可選壽司、烤物或熟食。地址：〒920-0905 石川県金沢市上近江町50。入場免費，多數店舖約9:00至17:00營業，各店休息日不同。

5. 東茶屋街

街區保留木造町家與茶屋建築，名稱中的「町」就是街區之意。真正的看點不是紀念品店，而是細格子窗、狹窄巷道及傳統建築尺度。地址：〒920-0831 石川県金沢市東山1丁目。街區全天可步行，免費參觀；茶屋、工藝店多於10:00至17:00營業。

實用資訊

從金澤站前往近江町市場，可步行約15至20分鐘或乘巴士；兼六園、金澤城、21世紀美術館適合串成步行路線，再轉往東茶屋街。市內巴士一般需另付車資，因此不要把 JR Pass 當成金澤全交通通行證。景點門票大致由免費至約¥1,500，當代藝術特展及茶屋體驗可能更高，實際以現場公告為準。

旅遊小提示

抵達後先在金澤站預約後續長途列車指定席，賞櫻、紅葉及連假尤其重要。雨雪天要穿防滑鞋，金澤降水較頻繁；冬季也應預留列車延誤緩衝。日本有地震及颱風風險，出發前確認天氣、JR 執行資訊與住宿避難路線，手機開啟緊急通知。最有效率的決策很簡單：只玩金澤就逐程購票；跨兩至三個北陸城市，再比較區域通票；東京與關西均納入行程，才進一步評估較廣域的 JR Pass。
