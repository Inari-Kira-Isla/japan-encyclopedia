金澤交通攻略：日本 JR Pass 暢遊石川縣的成本效益分析

2026-05-29 2223 字
金澤交通 JR Pass 石川縣 北陸旅遊 金澤景點

許多人以為金澤像札幌或仙台一樣，有專屬的「金澤 JR Pass」，實際上 JR 鐵路公司並未推出以「金澤」命名的周遊券。這是一個常見的誤解——正確的理解是：金澤作為北陸 JR 線的重要樞紐，持續日本全國或區域性 JR Pass 都能抵達，且在使用上有特殊的成本優勢值得深入探討。

金澤市位於石川縣中部，從東京搭乘 JR 北陸新高鐵直達約 2 小時 28 分鐘（指定席票價約 ¥14,000），從大阪出發約 3 小時。這座城市曾是加賀藩的城下町，以兼六園、金箔工藝與近江町市場聞名於世。對於外國旅客而言，理解如何有效運用 JR Pass 是控制交通費的關鍵。

金澤適用的 JR Pass 方案

**JR 全國 pass** 是最直接的選擇：\n- JR Pass 全國版（7 日效期）成人票 ¥29,650，涵蓋 JR 旗下所有線路包括 JR 西日本、北陸鐵道與IR石川鐵道。若行程涵蓋東京至金澤再到大阪或京都，這張 pass 能發揮最大效益。

  • 但若僅走東京—金澤往返，全國版未必划算，這時就要考量其他方案。

**JR 關西&北陸地區 pass**（7 日 ¥26,000）覆蓋關西機場至金澤的 HARUKA 與北陸線，適合從關西機場進出、玩完京阪奈後北上的旅客。這張 pass 在關西機場的 JR 服務視窗即可兌換，識別護照即可。

  • 不過此 pass 不含東京至金澤段，需另外購票。

**北陸地區鐵路周遊券**（4 日 ¥12,000）專為純北陸深度遊設計，可從大阪或京都上車，涵蓋金澤、加賀溫泉、永平寺等景點，對只停留石川縣的旅客CP值最高。

  • 這張票在大阪、新大阪、金澤站都能購買。

從不同城市出發的成本比較

計算持有 JR Pass 與單獨購票的成本差異，是行程規劃的首要功課。從東京赴金澤的新幹線單程約 ¥14,000，來回 ¥28,000，若加上金澤市內移動（ JR 石川鐵道線至和倉溫泉約 ¥2,400），基本交通費逼近 ¥33,000。此時 7 日全國版 ¥29,650 的價值就浮現了——前提是你的行程不只金澤一地。

從大阪出發單程 ¥10,000 左右，來回 ¥20,000。這時關西&北陸地區 pass ¥26,000 反而比單買還貴，除非你搭配關西機場 HARUKA（單程 ¥3,000 起）+ 京都大阪市內交通費才劃得來。最精明的選擇是「去程單買、回程用區域 pass」的混搭策略，或者利用金澤周邊的「城下町金慄」免費短程優惠。

推薦沿線 JR Pass 可抵達的金澤景點

**兼六園**：日本三大名園之一，春季賞櫻、秋季觀楓，冬季可看著名的「雪吊」景色。門票 ¥310，距離金澤站公車 15 分鐘。JR Pass 持有者可在金澤站換乘周遊公車（單程 ¥200，一日券 ¥600）。

**東茶屋街**：儲存完好的江戶時代茶屋街建築，以金箔工藝聞名。漫步其中可見各種金箔冰淇淋（¥800-1200）、金箔工藝品（¥1500起），感受傳統工藝之美。此街區需步行或搭乘公車前往。

**金澤 21 世紀美術館**：由建築師妹島和世設計，常有當代設計展覽，部分展覽需購票（¥500-1800）。館內的「游泳池」裝置是打卡熱點，距離兼六園步行 10 分鐘。

**近江町市場**：被稱為「金澤人的廚房」，海鮮蓋飯（¥1500-2500）、螃蟹料理遠近馳名。早晨 7 時開門，下午 5 時打烊。從金澤站步行 12 分鐘可達。

**和倉溫泉**：位於七尾海岸，日本北方最古老的溫泉鄉之一。從金澤站搭乘 JR 七尾線約 40 分鐘達和倉溫泉站，溫泉街沿海分佈，宿坊一泊二食 ¥8,000-25,000。夏季可兼程砂浴體驗。適合持 JR Pass 利用移動日的前後安排串聯。

實用資訊與成本最佳化建議

從臺灣或香港出發的旅客，常犯的錯誤是「到了日本才研究 JR Pass」。其實在出發前就該比較「全程單獨購票」與「JR Pass」的價格差距。一般原則是：行程跨越 3 城市以上、或單程交通費合計接近 pass 價格的 70%，才值得購買。

  • 另外，海外購買的 JR Pass 匯率因素也要一併計算，避開日本當地購買的高峰期匯率差。

金澤站的 JR 服務視窗（綠色視窗）提供外國護照持有者的 JR Pass 兌換業務，營業時間 07:00-22:00。建議提早排隊，旺季等候時間可達 30 分鐘。站內也設有 JR West Travel Service Center，可諮詢中文服務人員。

如果行程只在金澤、石川縣內移動，普通的 ICOCA 或 Suica（西瓜卡）搭配區間購票可能比 JR Pass 更省——例如金澤至和倉溫泉單程 ¥2,400、來回 ¥4,800，遠比買一張 pass 划算。

旅遊小提示

持 JR Pass 搭乘，北陸新幹線の「指定席」不用另外訂座，即使自由座車廂已滿，只要出示 pass 就能進入，不過自由席車廂通常較擁擠，建議提早在視窗預訂指定席。

、金澤的巴士一日券（¥600）可視行程密度決定是否購買，若一天會坐到 3 次公車以上，買一日券較值。

最後提醒，金澤的JR Pass選擇沒有標準答案，最重要的是先算出自己的「實際移動需求」——那些景點之間的移動距離與次數，才是決定買哪張 pass 的核心依據，而不是「聽說哪張很紅」。
