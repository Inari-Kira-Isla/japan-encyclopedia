簡介

遊金澤是否需要 JR Pass，關鍵不在「會不會搭 JR」，而在金澤前後還安排多少跨城移動。全國版 Japan Rail Pass 主要處理東京、敦賀、京都、大阪等城市與金澤之間的 JR 行程；抵達金澤駅後，兼六園、東茶屋街及近江町市場等核心景點，多數仍要步行或乘搭市內巴士，通常不在 JR Pass 覆蓋範圍內。

對帶長者、兒童或大型行李的旅客，我更建議把 Pass 當成「城際交通工具」，不要硬追求每日回本。由東京出發可乘北陸新幹線直達金澤；由京都或大阪前往，常見走法是乘特急列車至敦賀，再轉北陸新幹線。這段轉乘比昔日直達方式多一道程式，排程時應預留找月臺、使用升降機及搬執行李的時間。

特色亮點

金澤最適合納入東京—北陸—關西的單向行程，而不是由大阪或東京每日長途往返。Pass 的真正優勢是把多段新幹線及特急列車整合，同時降低臨時改動城市次序的壓力。若行程只有東京往返金澤一次，單買車票往往更容易判斷；若再加入富山、長野、京都或大阪，才應逐段比較全國版或區域型鐵路周遊券。

需要特別留意的是，JR Pass 不等於所有交通免費。金澤市內巴士、部分觀光巴士及非 JR 鐵路通常要另付費；指定席亦應提前劃位。大型行李須遵守列車的行李規定，不能預設任何座位旁都有足夠空間。

推薦地點

1. 金澤駅、鼓門及もてなしドーム
地址：〒920-0858 石川県金沢市木ノ新保町1-1。這裡不只是到埗點，也是檢查轉乘動線的最佳位置。東口的鼓門與玻璃穹頂適合短時間拍攝；站內集中餐飲、伴手禮及旅遊資訊，雨雪天抵達也不用立刻拖行李外出。帶長者者可先寄存行李，再轉乘巴士進城。

2. 近江町市場
地址：〒920-0905 石川県金沢市上近江町50。市場的強項是北陸海產、加賀蔬菜與即食料理，但熱門海鮮丼在午市容易排隊，價格也高於一般定食。從金澤駅步行約15至20分鐘，或另付費乘巴士前往。近年航空燃油附加費及生鮮物流成本上升，部分海產價格可能波動，現場牌價比舊攻略更可靠。

3. 金澤城公園
地址：〒920-0937 石川県金沢市丸の內1-1。石川門、復原櫓與多種石垣工法，能看出金澤作為加賀藩城下町的結構。公園大部分割槽域可免費散步，部分復原建築另行收費。園區範圍大且有坡道，與兼六園同日遊覽時，長者行程宜刪減其他景點。

4. 兼六園
地址：〒920-0936 石川県金沢市兼六町1。兼六園的價值不只在櫻花或雪景，而是池泉、借景、燈籠與松樹養護共同形成的迴遊式庭園。冬季可能積雪或結冰，雨天石階亦較滑；輪椅及嬰兒車旅客應優先選較平緩入口。入園費通常為數百日圓，開園時間隨季節調整。

5. 東茶屋街
地址：〒920-0831 石川県金沢市東山1丁目。茶屋建築的木格子街景儲存完整，適合觀察金澤町家尺度及傳統藝能文化。抹茶甜點店集中，但下午人流最密，想拍攝安靜街景可早上前往。這裡不是 JR 景點，從金澤駅須乘巴士、計程車或步行接駁。

實用資訊

東京方向以北陸新幹線為主；京都、大阪方向通常在敦賀轉乘。實際可乘列車、指定席規則及票價會調整，購買前應用自己的日期逐段核算，不直接套用舊版 JR Pass 價格。市內移動可預留每日約¥800至¥1,500，視巴士次數、步行能力及是否乘計程車而定；景點門票與餐費另計。

市場店舖多在早上至下午營業，茶屋街店舖常約上午開門、傍晚前後休息；庭園及文化設施則可能因季節、維修或活動更改時間。出發前應以營運單位公告為準。

旅遊小提示

雪季、梅雨及颱風期間，北陸列車可能延誤或停駛，不要把跨城列車與國際航班排得太緊。手機應開啟日本災害通知，住宿時確認避難出口；遇地震先保護頭部，待搖晃停止後依車站或館方指示行動。若同行者行動較慢，敦賀轉乘至少保留一班車的彈性，金澤住宿則選金澤駅附近，可減少拖行李乘巴士的負擔。
