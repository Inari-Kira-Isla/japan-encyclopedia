金澤 JR Pass 攻略：以轉乘負擔決定是否購買的北陸慢遊指南

2026-08-21 1470 字
金澤自由行 JR Pass 北陸交通

簡介

金澤的 JR Pass，真正用途不是在市內無限乘車，而是處理「如何抵達金澤」以及後續跨城移動。從東京出發，可乘北陸新幹線前往金澤，車程約2.5小時；若行程還包括富山、福井或其他 JR 可達城市，鐵路周遊券才較容易發揮價值。只在金澤停留兩三天、主要遊覽茶屋街與傳統街區的旅客，則不應因為看見 JR 標誌便直接購買全國版 Pass。

特色亮點

判斷是否需要 JR Pass，可用三個問題快速篩選：是否有兩段以上長途 JR 移動、是否會頻繁跨縣，以及指定席與行李安排能否降低旅途壓力。金澤站雖然是北陸鐵路樞紐，但兼六園、東茶屋街及近江町市場等核心景點，末段通常依靠巴士或步行，相關費用多數須另付。對帶父母或大型行李的旅客，少一次轉乘、預留指定席及避開雨雪，比單純追求最低票價更重要。

推薦地點

1. 金澤站、鼓門

地址：〒920-0858 石川県金沢市木ノ新保町1-1。鼓門與玻璃穹頂「款待圓頂」集中在車站東口，是理解金澤傳統與現代設計的起點。若持合適的 JR Pass，可在此銜接北陸新幹線或其他受涵蓋的 JR 路線；大型行李旅客也適合先寄存行李，再開始市內遊覽。

2. 兼六園

地址：〒920-0936 石川県金沢市兼六町1。兼六園的看點不是單一打卡位，而是借水景、地形與四季植栽形成的迴遊式庭園。春季櫻花、秋季紅葉及冬季雪吊各有特色，但園路較長且部分地面不平，與長輩同行宜預留約90分鐘。由金澤站乘市內巴士前往，通常不屬 JR Pass 覆蓋範圍。

3. 金澤城公園

地址：〒920-0937 石川県金沢市丸の內1-1。公園與兼六園相鄰，適合排在同一天，減少反覆乘車。菱櫓、五十間長屋及石川門可看出不同時期的城郭防禦與木造復原工法；公園部分割槽域可免費進入，特定建築展示另行收費。

4. 東茶屋街

地址：〒920-0831 石川県金沢市東山1丁目。這裡保留格子戶町屋與昔日茶屋空間，適合觀察金澤金箔、和菓子及傳統工藝如何融入現代商業。上午人流較少，也較容易看清街道尺度；午後旅行團集中，狹窄街巷會明顯擁擠。由金澤站前往仍以巴士加步行較實際。

5. 近江町市場

地址：〒920-0905 石川県金沢市上近江町50。市場適合作為抵達日午餐點，而非單純安排成海鮮打卡站。蟹類、甜蝦、能登與北陸水產會隨季節及供應狀況調整價格；熱門海鮮丼常約¥2,000以上，先看標價與份量再排隊，比只追逐社群名店有效率。

實用資訊

從東京前往金澤可利用北陸新幹線，約2.5小時。由大阪或京都方向前往時，可能涉及特急列車、新幹線或轉乘安排，應按旅行日期核對實際路線及 Pass 覆蓋區間。全國版與區域版 JR Pass 的價格和適用列車可能調整，購買前應把每段車程列出，確認指定席、轉乘路段及非 JR 交通是否另付費。

金澤市內景點多集中於車站東南面，巴士加步行通常比反覆尋找 JR 車站方便。兼六園一般日間開放，時間會按季節調整；金澤城內收費設施、商店及市場攤檔亦各有休息日，清晨或傍晚行程應於出發前核對。景點基本預算可抓每處免費至約¥1,000，餐飲、巴士及工藝體驗另計。

旅遊小提示

雨具應放在隨身袋而非行李箱底部，金澤天氣變化快，冬季還要準備防滑鞋。地震或颱風期間，先檢視鐵路停駛與延誤資訊，住宿地點、金澤站及主要景點的避難出口也應在抵達後確認。若行程只有金澤市區，不買 JR Pass 往往更簡單；若以金澤為基地連遊多個北陸城市，才應逐段比較車資與覆蓋範圍。最實用的原則是：Pass 負責長距離，巴士與步行負責最後一公里。

常見問題

只遊覽金澤市區，需要購買 JR Pass 嗎？

通常沒有必要。兼六園、東茶屋街及近江町市場主要依靠市內巴士或步行，而非 JR；是否購買應取決於抵達金澤前後的長途鐵路行程。

JR Pass 是否包含金澤市內巴士？

不能一概而論，多數市內巴士不在一般 JR Pass 的主要覆蓋範圍內。購票前應核對所持 Pass 的最新適用交通工具，並為末段移動預留額外費用。
