簡介

JR Pass 對金澤的主要價值，是解決東京、關西或其他城市往返金澤的長距離 JR 車程，而不是包辦市內觀光。金澤站以外，兼六園、東茶屋街及近江町市場多半要轉乘巴士、計程車或步行，相關費用通常不在 JR Pass 覆蓋範圍內。因此，最實際的判斷方式不是隻看「有沒有 Pass」，而是逐段列出鐵路、轉乘與末段交通。

這篇特別適合帶長者、兒童或大型行李的旅客。金澤市中心景點集中，但石板路、雨雪與巴士上落車會放大體力負擔；把金澤安排成連住兩晚的慢遊基地，通常比每日拖行李換酒店舒服。

特色亮點

從東京出發，可利用北陸新幹線直達金澤；由大阪、京都方向前往，常見方式是乘特急列車至敦賀，再轉北陸新幹線。JR Pass 是否划算，取決於整段行程包含多少次長距離 JR 移動，不能只用單程金澤票價判斷。部分班次採全車指定席或熱門日期容易滿座，持 Pass 也不代表必定有位，櫻花季、紅葉期及日本連假宜提早劃位。

金澤站設有升降機、儲物櫃及行李服務，是整理行程的核心節點。若住宿不近巴士站，建議直接使用行李配送；少一次在敦賀或車站內搬運大型行李，往往比多省一段市內車資更有價值。

推薦地點

1. 金澤站鼓門、もてなしドーム
地址：〒920-0858 石川県金沢市木ノ新保町1-1。鼓門把傳統能樂鼓意象放進現代車站設計，玻璃穹頂則適合雨雪天候下集合與候車。站內可處理指定席、行李寄存及餐飲，建議抵達後先完成翌日車票安排，再輕裝進城。

2. 近江町市場
地址：〒920-0905 石川県金沢市上近江町50。市場以日本海海產、加賀蔬菜及即食料理見長。海鮮丼常見約¥1,500至¥4,000以上，價格受魚種與季節影響。上午選擇通常較完整，但走道繁忙，帶行李箱入內會妨礙自己與商戶，最好先寄存。

3. 金澤城公園
地址：〒920-0937 石川県金沢市丸の內1-1。石川門、復原櫓與不同年代的石垣，能看出加賀藩城郭的防禦與工藝。公園範圍大，長者宜從較平緩入口進入，不必勉強走完整圈；部分復原建築可能另收費。

4. 兼六園
地址：〒920-0936 石川県金沢市兼六町1。園內以池泉、曲水、徽軫燈籠及冬季雪吊聞名，四季景觀差異明顯。一般成人入園費約¥320，開園時間通常隨季節調整。園路存在坡度與砂礫，輪椅或膝力較弱者應預留更多時間。

5. 金澤21世紀美術館
地址：〒920-8509 石川県金沢市広坂1-2-1。圓形建築設有多個入口，適合與兼六園組成同區行程。交流區部分空間可免費進入，特展另行售票；熱門作品可能採時段或入場限制，不能把免費區等同整館免費。

實用資訊

東京方向以北陸新幹線最直接；大阪、京都方向通常在敦賀轉車。國家版或地區版 JR Pass 的有效區間、指定席規則及可乘列車不同，購買前應按實際日期逐段核對，票價與產品條款可能調整，不宜沿用舊攻略價格。

市內主要依靠路線巴士及觀光巴士，單程通常另付數百日圓；三至四人同行、遇雨雪或有長者時，短程計程車可能比多次轉乘更有效率。景點多在約09:00至17:00活動最穩妥，但市場、庭園與美術館各有休館日或季節時間，出發前應檢視官方公告。

旅遊小提示

把景點按區域串連：近江町市場配金澤城，兼六園配21世紀美術館，可減少重複乘車。東茶屋街留給另一個半天，避免一天塞滿所有地標。冬季鞋底要防滑，梅雨及颱風季準備輕便雨具；遇地震或強風停駛，先留在安全場所，檢視車站公告與官方防災資訊。跨城行程不要排到最後一班列車，轉乘至少預留20至30分鐘，帶大型行李時再增加緩衝。
