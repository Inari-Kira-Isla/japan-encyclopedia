簡介

金澤的 JR Pass 價值主要在「抵達金澤」及跨城市移動，而不是市內觀光。由東京出發可乘北陸新幹線直達金澤；從京都、大阪方向前往，通常須在敦賀轉乘北陸新幹線。對長者、親子或攜帶大型行李的旅客而言，是否值得買 Pass，不能只比較車資，還要計算轉乘次數、指定席需求及最後一段巴士交通。

全國版 Japan Rail Pass 一般可用於合資格的 JR 列車，但不同地區型 Pass 的適用區域、指定席規則及非 JR 路段可能不同。票價與產品內容會調整，最可靠的做法是列出每段行程，再核對當期官方適用範圍，避免用過時價格判斷回本。

特色亮點

金澤站是北陸觀光的核心樞紐，適合採用「少換酒店、放射式移動」策略。住在車站附近，可把行李留在酒店，再前往富山、福井或其他北陸城市；這種安排對膝關節不便、帶嬰兒車或冬季出遊的旅客特別實際。

需要留意的是，兼六園、金澤城、近江町市場及二十一世紀美術館都不在 JR 車站旁。JR Pass 通常不等於金澤市內巴士通行證，因此交通預算必須分成「城際 JR」與「市內末段」兩部分。若行程大多集中於金澤市中心，單買車票配合巴士或計程車，往往比購買全國版 Pass 更直接。

推薦地點

1. 金澤站、鼓門與遊客中心
地址：〒920-0858 石川縣金澤市木之新保町1-1。鼓門不是單純拍照點，而是整理行程的最佳起點。站內設有觀光資訊、餐飲、伴手禮與行李服務，升降機及無障礙動線亦相對完整。需要在敦賀轉乘的旅客，建議抵達後先寄存行李，避免拖箱搭乘擁擠巴士。

2. 近江町市場
地址：〒920-0905 石川縣金澤市上近江町50。市場以海鮮、加賀蔬菜及即食小吃為主，適合安排在抵達日午餐。各店價格差異明顯，海鮮丼常由約¥1,500起，高階蟹類料理可能遠高於此。市場通道較窄，午市人流集中，大型行李應留在車站或酒店。

3. 金澤城公園
地址：〒920-0937 石川縣金澤市丸之內1-1。石川門、菱櫓及復原城郭能清楚呈現加賀藩的防禦與建築格局。公園戶外區域通常可免費進入，部分建築內部另行收費。園區範圍大且有坡度，體力有限者可從兼六園一側安排單向遊覽，減少折返。

4. 兼六園
地址：〒920-0936 石川縣金澤市兼六町1。兼六園的重點不是單一花季，而是池泉、松樹、石橋與地形共同形成的回遊式庭園。成人門票參考約¥320，營業時間隨季節調整。雨雪後石路可能濕滑，長者宜穿防滑鞋，冬季亦要預留比地圖估算更長的步行時間。

5. 金澤二十一世紀美術館
地址：〒920-8509 石川縣金澤市廣坂1-2-1。圓形建築與多入口設計打破傳統美術館的正面動線，公共交流區與收費展覽區分開，適合與兼六園排在同一天。展覽門票依企劃而異，熱門作品可能需要整理券或預約，不應把免費公共區誤當成所有展覽均免費。

實用資訊

東京方向以北陸新幹線最省轉乘；京都、大阪方向通常經敦賀換車。持 Pass 也建議預約指定席，同行長者可減少在月臺候車及分散座位的風險。大型行李須依列車規定選擇合適座位或存放位置，不要假設所有車廂都有充足行李空間。

金澤市內主要依靠路線巴士、觀光迴圈巴士、步行與計程車。金澤站至近江町市場距離較短，之後可依近江町市場、金澤城、兼六園、二十一世紀美術館的順序移動，形成較少折返的動線。景點多在日間開放，但閉館日、最後入場時間及冬夏季時段可能改變，出發前應以設施公告為準。

費用方面，不宜只用 JR Pass 售價除以天數。應把東京或關西往返、北陸跨城次數、指定席需求逐段列出，再另加市內巴士、計程車、門票及行李寄存費。若只安排金澤兩三天且沒有長途跨城，Pass 未必能節省支出。

旅遊小提示

冬季北陸可能出現大雪、強風及列車延誤，夏秋亦須留意颱風和暴雨。手機應開啟日本災害通知，確認酒店避難路線，並在轉乘日保留緩衝時間。遇到地震時先遠離玻璃及易倒物件，不要急於衝出建築；列車停駛時依車站人員指示行動。

金澤常下雨，摺傘、防水鞋及行李套比多排一個景點更有用。行程若有長者，建議每天只設定一組主區域：車站與市場、或金澤城與兼六園。JR Pass 能縮短城市之間的距離，真正決定旅程是否輕鬆的，卻是轉乘、行李與市內最後一公里的安排。
