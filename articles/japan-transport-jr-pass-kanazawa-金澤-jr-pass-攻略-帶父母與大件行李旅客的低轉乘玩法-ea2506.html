金澤 JR Pass 攻略：帶父母與大件行李旅客的低轉乘玩法

2026-08-21 1726 字
金澤交通 JR Pass 北陸自由行

簡介

金澤的 JR Pass，主要價值不是市內觀光，而是解決前往金澤的城際鐵路費用。金澤站雖是北陸交通樞紐，但兼六園、近江町市場及茶屋街一帶多靠巴士或步行，不能把「JR 可到金澤」理解成抵達後所有交通都已包含。

這篇特別寫給帶父母、幼童或大型行李的旅客。選 Pass 時不要只計算票價差額，還要把轉乘次數、指定席、行李處理及冬季天候風險算進去。由東京出發，北陸新幹線直達金澤約2.5小時，是最省力的路線；由大阪或京都出發，通常先乘特急列車到敦賀，再轉北陸新幹線，長者同行時應預留充足轉乘時間。

特色亮點

全國版 Japan Rail Pass 適合行程同時跨越東京、北陸及關西等多個區域；若旅程集中在北陸與關西，區域型 Pass 往往更貼近實際動線。不過各 Pass 的售價、有效期、可乘列車及指定席規則會調整，購買前應以 JR 官方最新覆蓋範圍為準，不宜沿用舊攻略的固定價格。

判斷是否划算，可逐段列出「機場—城市—金澤—下一站」的 JR 車程，再標記巴士、地下鐵及私鐵路段。金澤市內巴士一般不屬 JR Pass 核心覆蓋，這部分應另備交通費。若只安排東京往返金澤一程，直接購買車票可能比全國版 Pass 更簡單；若還會前往京都、大阪或其他長途城市，Pass 的價值才較容易顯現。

推薦地點

1. 金澤站、鼓門與款待圓頂

地址：〒920-0858 石川県金沢市木ノ新保町1-1。這裡不只是到達點，也是整理行李與重新分組的最佳位置。東口鼓門適合拍攝城市第一張照片，站內則可處理餐飲、伴手禮及旅遊資訊。帶長者時，建議先把大型行李寄存或送往酒店，再開始市內行程，避免石板路與巴士上下車增加負擔。車站公共空間基本上全日可通行，商店約於08:30至20:00間個別營業。

2. 近江町市場

地址：〒920-0905 石川県金沢市上近江町50。市場以日本海海產、加賀蔬菜及即食料理見長，最適合安排在抵達日午餐，而不是拖著行李穿越攤檔。多數店舖約09:00至17:00營業，但休息日與售罄時間各異。參觀免費，海鮮丼常見預算約¥1,500至¥4,000。由金澤站可步行約15至20分鐘，體力不足者宜乘市內巴士，車資通常需另付。

3. 金澤城公園

地址：〒920-0937 石川県金沢市丸の內1-1。城郭的石垣、復原櫓與城門能直接看出加賀藩的防禦設計，與單純拍天守的城跡體驗不同。公園範圍通常免費，部分復原建築另行收費；一般開園約07:00至18:00，季節可能調整。它與兼六園相鄰，適合合併成半日路線，減少長者重複乘車。

4. 兼六園

地址：〒920-0936 石川県金沢市兼六町1。園內以池泉、曲水、松樹與高低地形構成連續景觀，冬季雪吊尤其具代表性。成人入園費約¥320，常規開園時間約07:00至18:00，冬季通常縮短。園內有坡道與碎石路，輪椅、手杖或雨雪天同行時，應放慢節奏並預留休息時間。

5. 金澤21世紀美術館

地址：〒920-8509 石川県金沢市広坂1-2-1。圓形建築、透明介面與公共空間本身就是展覽的一部分，適合不想全日只看傳統景點的旅客。交流區通常免費，展覽區依企劃收費，常見觀展預算約¥450至¥1,200；展覽區一般為10:00至18:00，週五、週六可能延長，休館日以館方安排為準。

實用資訊

東京方向可搭北陸新幹線前往金澤；大阪、京都方向通常經敦賀轉乘。持 Pass 仍應確認列車是否適用並預約指定席，尤其週末、連假與大型活動期間。大型行李旅客宜選擇靠近行李空間的座位，並把轉乘時間留得比導航建議更寬鬆。

市內可採「金澤站—近江町市場—金澤城—兼六園—21世紀美術館」單向移動，減少折返。主要景點預算由免費至約¥1,200，餐飲及市內巴士另計；各設施營業時間會因季節、維修及展期變動，出發前需再次確認。

旅遊小提示

冬季積雪會令步行速度明顯下降，夏末至秋季亦須留意颱風造成的列車延誤。手機應啟用日本災害警報，住宿後先確認避難出口，並準備少量現金、飲用水及行動電源。遇到地震時不要急著衝出建築物，先保護頭部並依現場人員指示行動。行程設計上，每日保留一段可刪減的景點，比排滿所有時段更能抵抗天候與交通變化。

常見問題

JR Pass 是否包含金澤市內巴士？

一般不能假設包含。JR Pass 主要處理前往金澤的JR城際交通，兼六園、近江町市場等景點的市內巴士通常需要另外付費；實際適用範圍應以所購 Pass 的最新條款為準。

只去東京和金澤，需要購買全國版 Japan Rail Pass 嗎？

未必。若只有東京至金澤單程或往返，應先比較直接購票與 Pass 的總成本；只有再加入京都、大阪等長途JR路段時，Pass 才較可能划算。
