東京 JR Pass 攻略：以東京為基地的跨城交通決策指南

2026-09-03 1461 字
東京交通 JR Pass 日本自由行

簡介

在東京使用 JR Pass，關鍵不是「一天搭多少次車」，而是有沒有安排足夠的 JR 長途移動。若旅程主要集中於淺草、銀座、新宿、澀谷及臺場，全國版 Japan Rail Pass 通常不划算，因為東京地下鐵、都營地下鐵、私鐵及多數巴士均不在覆蓋範圍內。它更適合以東京連住數晚，再乘新幹線或 JR 特急放射式前往外縣市的旅客。

特色亮點

JR Pass 的優勢是把跨城車資、指定席安排及多段 JR 轉乘整合在同一張通行證內，特別適合不想反覆購票的家庭、長者及攜帶大型行李者。東京市內可使用山手線、中央線、京濱東北線等 JR 路線，但不能把「車站有 JR」理解成整個行程都免費：抵達景點附近後，地下鐵、私鐵、巴士與纜車往往仍要另付費。

購買前可做一次覆蓋率審計：列出每段交通，分成 JR、新幹線、私鐵、地下鐵和巴士，再比較普通車票總額與通行證當期售價。由於 JR Pass 價格及適用列車規則可能調整，不應依賴舊文章中的固定價格。短途旅客也應同時比較 JR 東日本地區型周遊券及單買車票。

推薦地點

1. 橫濱

JR 橫濱駅：〒220-0011 神奈川県橫浜市西區高島2丁目16-1。從東京可乘 JR 東海道線或京濱東北線前往，班次密集，適合作為首次測試 JR 放射式旅行的目的地。港未來、紅磚倉庫與中華街並非全部緊貼 JR 車站，末段可能要步行、轉乘港未來線或巴士。

2. 鎌倉

JR 鎌倉駅：〒248-0006 神奈川県鎌倉市小町1丁目1-1。可由東京方向乘 JR 橫須賀線直達，減少轉車壓力。鶴岡八幡宮與小町通適合步行遊覽；若前往長谷寺、鎌倉大佛或江之島，通常需要另付江之電車資。這條路線最能示範 JR Pass 只解決主幹交通、不包辦景點末段的限制。

3. 小田原

JR 小田原駅：〒250-0011 神奈川県小田原市栄町1丁目1-1。小田原位於東京與箱根之間，可乘符合通行證規則的新幹線或 JR 普通列車抵達。小田原城可從車站步行前往；進入箱根後使用的箱根登山電車、巴士、纜車及空中纜車，多數不屬 JR 系統。若目的地只有箱根，應把當地周遊券與 JR 車程分開計算。

4. 日光

JR 日光駅：〒321-1413 栃木県日光市相生町。持 JR Pass 可考慮經宇都宮轉乘 JR 日光線，避開私鐵不受覆蓋的問題。缺點是轉乘及總時間需要仔細配合，抵達後前往東照宮、中禪寺湖等地仍須搭巴士。秋季紅葉期道路容易擠塞，不宜把回程銜接排得太緊。

實用資訊

全國版 JR Pass 須按連續日數使用，不能任意拆開日期；部分高速列車、特殊席別或額外服務可能有限制或補費要求。實際售價、可乘列車與指定席規則，以出發前的 JR 官方公告為準。JR 車站一般由清晨營運至深夜，但綠色視窗、指定席售票機及各景點開放時間不同，長途列車也不是通宵行駛。熱門季節應提早預約指定席，大型行李則要確認相應座位及預約規定。

旅遊小提示

把東京安排在通行證啟用前後，可用交通 IC 卡處理市內地下鐵與私鐵，把 JR Pass 的有效日集中留給日光、小田原或更遠的跨城行程。東京駅、新宿駅等大型車站步行距離很長，長者同行時至少預留15至20分鐘轉乘緩衝。

日本可能遇上地震、颱風、大雪或豪雨，列車會因安全檢查停駛。出發前檢視營運資訊，手機儲存住宿地址與緊急聯絡方式，並避免把最後一班長途列車當成唯一回程方案。JR Pass 是交通工具，不是行程保險；真正好用的排法，是讓每一天即使取消一段遠行，也有可替換的東京市內方案。

常見問題

只在東京市內活動，需要購買 JR Pass 嗎？

通常不需要。東京大量景點依賴地下鐵、都營線及私鐵，使用交通 IC 卡或合適的市內票券通常更直接。

JR Pass 可以搭乘東京所有列車嗎？

不可以。它主要涵蓋符合規則的 JR 路線，東京地下鐵、都營地下鐵、江之電及多數私鐵和巴士需要另行付費。
