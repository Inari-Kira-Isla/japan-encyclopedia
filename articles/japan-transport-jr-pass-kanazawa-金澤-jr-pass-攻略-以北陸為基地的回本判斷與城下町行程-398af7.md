簡介
金澤沒有專屬的「Kanazawa JR Pass」。真正要判斷的是：你的行程是否包含東京、富山、福井、京都或大阪等跨城市移動。若只在金澤市內觀光，JR Pass 幾乎派不上用場，因為兼六園、金澤城、東茶屋街等核心景點主要靠巴士與步行串聯；若以金澤為基地探索北陸，涵蓋北陸新幹線的全國版或 JR 西日本地區周遊券才可能有價值。

特色亮點
金澤最大的交通優勢不是「車票便宜」，而是位置適合做多點進出。東京搭北陸新幹線前往金澤約2.5小時；向東可接富山，向西可經福井、敦賀轉往京都與大阪。2024年北陸新幹線延伸至敦賀後，金澤往關西通常需要在敦賀轉乘特急列車，不宜再把大阪至金澤理解為全程一班直達。

選票可用簡單決策判斷：東京進、關西出，並在北陸停留數晚，可比較全國版與涵蓋北陸、關西的地區券；只走大阪—金澤來回，優先比較 JR 西日本相關地區券；只玩金澤兩三天，單買車票加市內巴士券通常更直接。各通票價格及適用列車可能調整，購買前應按官網最新條款計算，不宜只憑「搭一次新幹線便回本」決定。

推薦地點
1. 金澤站、鼓門：〒920-0858 石川県金沢市木ノ新保町1-1。站內集合新幹線、在來線、巴士總站與旅遊服務設施，是安排北陸行程最有效率的起點。鼓門與玻璃穹頂「款待圓頂」本身也是地標；住宿選在車站附近，特別適合翌日早班前往富山或福井的旅客。

2. 兼六園：〒920-0936 石川県金沢市兼六町1。園內以徽軫燈籠、霞之池、曲水與冬季雪吊聞名，景觀重點隨季節變化，不是拍完入口便結束的公園。成人入園費約¥320，清晨前往通常比旅行團集中抵達後舒服。

3. 金澤城公園：〒920-0937 石川県金沢市丸の內1-1。石川門、五十間長屋與不同年代的石垣，能看出加賀藩城郭的防禦與重建脈絡。公園主要區域免費，部分復原建築另行收費；與兼六園隔路相對，應排在同一時段，避免重複搭車。

4. 東茶屋街：〒920-0831 石川県金沢市東山1丁目。真正看點是儲存下來的茶屋建築、木蟲籠格子與狹長町家格局。主街日間較擁擠，可向淺野川及周邊小巷延伸步行；茶屋、工藝店與金箔商品價格差距大，購物前先確認是金箔工藝、食用金箔還是一般鍍金紀念品。

5. 長町武家屋敷跡：〒920-0865 石川県金沢市長町。土塀、石板路及武家住宅水路，呈現與茶屋街完全不同的城下町階層。雨天路面有氣氛但較滑，建議穿防滑鞋；可由香林坊步行進入，不必為一兩站巴士排隊。

實用資訊
金澤站至主要景點可乘城下町周遊巴士或一般路線巴士，JR Pass 通常不能代替市內巴士車資。兼六園、金澤城與東茶屋街多在約08:00至18:00之間活動最方便，但各設施會按季節、展館及店家調整時間。景點入場多為免費至數百日圓，較大的交通支出反而是跨城市新幹線與特急列車。乘坐指定席列車時，應確認通票是否涵蓋該區間並提前劃位；大型行李也要遵守列車預約及放置規則。

旅遊小提示
金澤市中心景點密集，建議採「巴士到最遠點、一路步行回市區」的走法，減少塞車與候車時間。冬季可能降雪，雨具、防水鞋及保暖層比堆滿景點更重要；夏秋遇颱風或大雨，北陸新幹線與特急列車亦可能延誤。抵達後先確認氣象、避難場所與列車執行資訊，手機開啟日本緊急警報，並為跨區轉乘預留至少30分鐘。JR Pass 是跨城工具，不是金澤市內萬用票；先排路線，再選票，通常比先買通票後硬湊車程更省錢。
