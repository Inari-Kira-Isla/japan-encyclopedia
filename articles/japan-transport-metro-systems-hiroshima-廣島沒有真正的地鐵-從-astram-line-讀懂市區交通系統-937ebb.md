簡介

廣島並沒有東京、大阪那種市營地下鐵網路。旅客搜尋「Hiroshima Metro Systems」時，最容易混淆的是 Astram Line（アストラムライン）：它正式名稱為廣島高速交通廣島新交通1號線，只有本通至新白島一帶位於地下，其後大部分路段轉為高架，採膠輪導向式自動運輸系統。因此，把它理解成「市中心地下捷運＋西北部高架線」會比直接稱為廣島地鐵準確。

廣島交通的核心不是單一系統，而是三者分工：Astram Line 負責本通、縣廳與西北住宅區；廣島電鐵路面電車覆蓋廣島站、原爆圓頂館、紙屋町及宮島口方向；JR 則適合新白島轉乘、前往宮島口或跨城市移動。對短期旅客而言，先按目的地選系統，通常比研究複雜通票更省時間。

特色亮點

Astram Line 的優勢是路線單純、站名清晰，也不受市中心道路擠塞影響。全線由本通通往廣域公園前，車廂行駛平穩；本通、縣廳前、城北及新白島等站位於地下，離開中心區後可從高架路段觀察廣島西北部的住宅與丘陵地貌。

它的限制同樣明顯：不到廣島站、和平紀念公園正門及宮島。若酒店位於廣島站附近，路面電車或巴士通常更直接；若住在本通、紙屋町一帶，Astram Line 才能真正成為行程骨架。這種「地下線不是全能主角」的結構，正是規劃廣島交通時最重要的判斷。

推薦地點

1. 本通站與本通商店街
本通站是 Astram Line 市中心端點，出站便可進入有遮蔽的本通商店街。這裡適合安排購物、用餐及雨天備案，步行前往紙屋町、原爆圓頂館也很方便。它最大的價值不是單一景點，而是讓旅客把交通、補給與觀光集中在同一區域。

2. 縣廳前站與廣島城
縣廳前站位於行政與商業核心，步行可到廣島城及中央公園。廣島城周邊範圍比照片看起來大，利用此站進場，可減少從廣島站一路步行的體力消耗。遇上炎夏或下雨，地下區段也比轉乘地面巴士穩定。

3. 城北站與縮景園北側街區
城北站適合喜歡避開主要觀光人流的旅客。由此可探索河岸及城北生活區，再按體力步行往廣島城；它不是最快的打卡路線，卻能看到較貼近日常的城市尺度。若要前往縮景園，仍需預留步行時間，不能把城北站誤當成園區門口站。

4. 新白島站
新白島是 Astram Line 與 JR 山陽本線的重要轉乘點。由市中心前往宮島口、橫川或其他 JR 沿線地區時，在此換乘往往比返回廣島站更有效率。車站本身以白色筒狀結構著稱，也清楚呈現廣島地下交通與地面鐵路的銜接方式。

5. 廣域公園前站
這是 Astram Line 終點站，主要服務廣島廣域公園及周邊體育設施。舉行足球賽或大型活動時，列車可能明顯擁擠，回程也容易集中排隊。一般觀光客未必需要專程前往，但想觀察廣島郊區發展，這段高架旅程比市中心地下區段更有特色。

實用資訊

Astram Line 通常由清晨約6時營運至午夜前後，實際首末班車依車站及日期而異。車費採距離制，成人單程大致由¥190起，全線車程約四十分鐘；兒童票、活動日班次及各類乘車券應以當日公告為準。主要入口集中於本通、縣廳前與新白島，使用交通IC卡可減少購票時間。

從廣島站出發不能直接搭 Astram Line。前往本通可乘廣島電鐵或巴士，再轉入地下車站；前往宮島則多數情況使用 JR 或廣島電鐵。不要因行程包含新幹線便直接購買全國版 JR Pass，應按跨城市車程逐段比較，而且 JR Pass 價格會調整，出發前須查閱最新官方資料。

旅遊小提示

只遊覽和平紀念公園、廣島城與本通時，步行配合路面電車通常已足夠；加入新白島或西北部目的地後，Astram Line 才更能節省時間。繁忙時段避免攜帶大型行李進入通勤車廂，車站內依指示排隊即可，偶爾站錯位置不是嚴重失禮，及時讓出通道便可。

廣島夏季炎熱，颱風季可能出現停駛或班次調整；地震發生後，列車也可能先行安全檢查。建議手機開啟日本災害通知，儲存酒店地址與離線地圖，並在大型活動日提早確認末班車。這套系統最適合的用法不是「全程只坐捷運」，而是以本通和新白島為轉乘節點，靈活連線路面電車與 JR。
