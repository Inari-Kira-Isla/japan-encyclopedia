神戶 JR Pass 攻略：以港都作基地，串連姬路、明石與有馬溫泉

2026-08-14 2018 字
神戶JR Pass 關西自由行 兵庫交通攻略

簡介

神戶沒有名為「Kobe JR Pass」的專屬通票。旅客實際使用的是全國版 Japan Rail Pass，或 JR 西日本發行、涵蓋神戶的區域鐵路周遊券。選擇關鍵不是「會不會在神戶搭車」，而是住宿期間會否頻繁前往姬路、岡山、大阪或京都。

若行程集中在三宮、北野、神戶港及有馬溫泉，JR Pass 通常不是最省錢的選擇，因為神戶市營地下鐵、巴士、Port Liner、六甲纜車及前往有馬溫泉的多數路線均不屬於 JR。相反，以神戶作為住宿基地，每天向西前往明石、姬路甚至岡山，區域型 JR Pass 才較容易回本。這種「住神戶、避開大阪住宿高峰、利用新快速與新幹線放射式遊覽」的安排，尤其適合第二次以上到訪關西的旅客。

特色亮點

神戶最實用的 JR 車站是三ノ宮、元町、神戶及新神戶站。三ノ宮站位於市中心，JR 神戶線的新快速可直接連線大阪、京都、明石及姬路；新神戶站則是山陽新幹線車站，但它與市中心的 JR 三ノ宮站並不相連，需要轉乘神戶市營地下鐵或巴士。

規劃時要分清「普通 JR 線」與「山陽新幹線」。部分 JR 西日本區域券涵蓋兩者，部分只覆蓋在來線；全國版通票亦可能對特定最高等級列車設有限制。不要只看地圖上的涵蓋範圍，購買前還要核對可搭列車、指定席規則及使用日數。由於票價與產品內容會調整，本文不列容易過期的 JR Pass 固定售價。

推薦地點

1. 姬路城

地址：〒670-0012 兵庫県姫路市本町68

從 JR 三ノ宮站乘新快速約一小時可達姬路，若所持通票包含山陽新幹線，由新神戶出發可再縮短交通時間。姬路城保留白色城郭、複雜防禦動線與木造天守，不只是拍攝外觀的景點。建議預留三至四小時，才能連同西之丸及好古園一併遊覽。單次來回距離較長，是判斷區域 JR Pass 是否划算的重要行程。

2. 明石公園與魚之棚商店街

明石公園：〒673-0847 兵庫県明石市明石公園1-27

由三ノ宮乘 JR 新快速約十五至二十分鐘。明石公園保留明石城的巽櫓與坤櫓，從車站步行即可抵達；魚之棚商店街則可觀察明石鯛、章魚及海產加工店的港町飲食文化。這裡比大阪黑門市場節奏平實，適合想吃明石燒、又不希望整天耗在熱門觀光區的旅客。

3. 神戶港與南京町

南京町：〒650-0023 兵庫県神戸市中央區栄町通1丁目3

從 JR 元町站步行約五分鐘可達南京町，再步行前往美利堅公園及港區。這段路線的優點是幾乎不需額外轉乘私鐵或地下鐵，最能發揮 JR Pass 在神戶市中心的便利性。南京町適合少量多餐，但週末中午人流密集；港區傍晚景觀較佳，可把用餐與夜景排在同一條步行動線。

4. 布引香草園與布引瀑布

地址：〒650-0002 兵庫県神戸市中央區北野町1丁目4-3

景區入口鄰近新神戶站，適合抵達或離開神戶當日順遊。纜車沿山坡上升，可俯瞰港灣與市區；若不想支付纜車費，也可由新神戶站步行前往布引瀑布。要注意纜車不屬於 JR Pass 範圍，持通票也需另外購票。

5. 有馬溫泉

地址：〒651-1401 兵庫県神戸市北區有馬町

有馬以含鐵、呈褐色的金泉及透明銀泉聞名，是神戶最具代表性的溫泉區。不過 JR Pass 無法直接送你到有馬溫泉站，通常要由三宮搭地下鐵及神戶電鐵，或使用巴士。它適合安排半日或住宿一晚；若只為了「用盡 JR Pass」而加入，反而會增加轉乘與額外車費。

實用資訊

神戶市內以 JR 神戶線配合步行最有效率：三ノ宮適合北野與市中心，元町適合南京町，神戶站適合港區西側。新神戶站與三ノ宮之間應預留約二十至三十分鐘轉乘時間，別把兩站誤認為同一個交通樞紐。

費用方面，JR Pass 應以整段跨城市行程比較，而不是用一兩次市內乘車判斷。僅遊神戶市區者，交通預算可按每日約¥1,000至¥2,500估算；加入有馬溫泉、纜車或觀光設施後，另預留約¥2,000至¥6,000。JR Pass、區域券及景點門票均可能調整，出發前應查閱發行公司的當期售價與適用範圍。

JR 列車大致由清晨執行至深夜，但班次依日期及路線不同。姬路城等收費設施多在日間開放，常見參觀時段約09:00至17:00；商店街、纜車及溫泉設施各自營業，季節、維修與節假日可能改動，不應把列車執行時間當成景點營業時間。

旅遊小提示

把住宿設在三宮附近，比住新神戶站旁更適合日常用餐與市內移動；只有頻繁乘坐山陽新幹線時，新神戶才更具優勢。行李多的旅客不要低估兩站之間的轉乘成本。

遇上地震，先遠離玻璃與掉落物，列車停駛時依車站人員指示行動，不要自行走上軌道。夏末至秋季若有颱風接近，JR 西日本可能提前減班或計畫停駛，當天不要安排無法取消的跨城接駁。手機可啟用日本災害通知，並保留一晚備用藥物、飲用水及少量現金。神戶的通票策略其實很簡單：市內慢遊買單程票，跨城密集移動才比較 JR Pass；先畫出每天的目的地，再決定買哪一張券。
