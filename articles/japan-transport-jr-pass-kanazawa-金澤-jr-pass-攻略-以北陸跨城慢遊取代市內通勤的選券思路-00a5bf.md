簡介
金澤沒有「金澤專屬 JR Pass」。對旅客而言，JR 周遊券的真正價值不是往返兼六園，而是把金澤設定為北陸旅行基地，串連富山、福井、加賀溫泉與東京或大阪。金澤市內主要景點集中在巴士與步行範圍，多數 JR Pass 不包含市區巴士；如果只遊金澤兩三天，單買車票通常更直接。只有安排多次跨城移動，或由東京進、大阪出的開口行程，才值得比較北陸拱型鐵路周遊券、關西—北陸地區鐵路周遊券及全國版 Japan Rail Pass。

特色亮點
金澤站是北陸新幹線的重要節點。由東京方向可乘北陸新幹線抵達；由大阪、京都方向前往，現時通常先乘特急列車到敦賀，再轉北陸新幹線。選券時不要只看總天數，要把「長途段、轉乘段、指定席使用次數」逐項列出。北陸拱型路線適合東京入境、經長野與金澤、最後前往關西的旅客；關西—北陸類票券較適合大阪往返並深入福井、富山者。全國版 JR Pass 覆蓋較廣，但單純玩北陸未必划算，而且部分最快等級列車或特定服務可能另有使用限制，購買前應核對當期適用範圍。

推薦地點
1. 富山：從金澤乘北陸新幹線即可快速抵達，適合加入半日或一日行程。富巖運河環水公園以水岸、橋景與開闊草地見長，與金澤的城下町氣氛形成鮮明對比。若票券已涵蓋新幹線，跨城成本優勢最明顯。

2. 福井縣立恐龍博物館：〒911-8601 福井県勝山市村岡町寺尾51-11。館內以大型恐龍骨架、化石研究及立體展示聞名，並非只適合兒童。由金澤乘北陸新幹線至福井，再轉地方鐵路與巴士；後段通常不屬 JR，需另付費，也要預留轉乘時間。

3. 加賀溫泉鄉：以山代、山中、片山津及粟津等溫泉區組成。北陸新幹線可到加賀溫泉駅，但車站並不等於溫泉街，仍須轉乘巴士或旅館接駁。這裡適合把周遊券省下的長途交通預算轉投一泊二食，住宿常見約¥15,000起，高階旅館可達¥40,000以上。

4. 白川鄉：〒501-5627 岐阜県大野郡白川村荻町。合掌造聚落是金澤最受歡迎的跨縣一日遊之一，但沒有 JR 車站，通常由金澤站乘高速巴士前往，JR Pass 一般不能使用。把它列入本文，是要提醒旅客：有 Pass 不代表北陸所有熱門景點都已包交通費，旺季更應提前預約巴士座位。

5. 金澤市內文化區：兼六園、金澤城公園、東茶屋街與近江町市場可組成一日步行加巴士路線。兼六園地址為〒920-0936 石川県金沢市兼六町1。東茶屋街適合品嘗金澤抹茶甜點與觀察茶屋建築，但熱門店午後容易排隊；市內段應另買巴士票或按次付費，不要為了使用 JR Pass 繞行。

實用資訊
金澤站旅遊服務與商店多集中於早上至晚間，各景點時間則不同；兼六園會依季節調整開園時段，博物館亦可能設休館日或預約制度。JR Pass 價格及適用列車會調整，本文不列固定售價；最可靠的做法是以出發日期查閱官方最新價格，再與東京—金澤、金澤—敦賀—京都或大阪，以及北陸區內各段單程票合計比較。若周遊券只比單買便宜少量，單買票反而保留改行程的彈性。

旅遊小提示
住宿選金澤站附近，適合頻繁搭新幹線；主攻兼六園與茶屋街，住香林坊一帶會更省市內交通時間。冬季北陸可能因大雪延誤，夏秋亦要留意颱風；手機應開啟日本氣象與防災通知，並避免把跨城轉乘排得太緊。地震發生時先遠離玻璃與掉落物，依車站或住宿人員指示行動。最實用的決策很簡單：只玩金澤就單買票；大阪往返並遊福井、富山才比較區域券；東京進、關西出則優先研究北陸拱型方案。
