金澤 JR Pass 完整指南：前往小京都的鐵道優惠方案

2026-07-28 2159 字
金澤 JR Pass 關西廣域周遊券 日本鐵路周遊券 北陸交通

許多旅客在規劃金澤行程時，常會搜尋「金澤 JR Pass」，卻發現當地並沒有所謂的「金澤專屬 JR Pass」。這個發現往往讓人困惑——難道沒有優惠的交通方式前往這座被譽為「小京都」的城市嗎？事實上，金澤作為石川縣的最大城市，雖然沒有獨立命名的鐵路周遊券，但有數種 JR Pass 方案能讓你從關西或東京前往金澤時省下不少費用。本文將針對不同出發地點，提供最實用的 JR Pass 選擇建議。

**為什麼金澤沒有專屬 JR Pass？**

金澤站是 JR 西日本北陸本線的重要據點，但金澤市內的鐵路系統主要屬於 IR 石川鐵道線與兼六園鐵道，這些屬於地方第三部門鐵道，並非 JR 營運範圍。因此，旅客無法透過單一金澤 Pass 暢遊全市。然而，這不表示你無法省下交通費——關鍵在於選對 JR Pass 的覆蓋範圍。

**從關西出發：關西廣域周遊券是首選**

如果你從大阪或京都出發，JR West 發行的「關西廣域周遊券」（Kansai Wide Area Pass）是前往金澤最划算的選擇。這張 Pass 定價約 ¥10,000（連續5天），涵蓋範圍包括：

  • 關西機場到大阪市區的 HARUKA 特急
  • 大阪、京都至金澤的 Thunderbird 特急（單程約2.5小時）
  • 嵐山、鞍馬、宇治、比叡山等關西經典景點
  • 無限次搭乘區域內的新幹線（指定席）

這張 Pass 的優勢在於「一券多用」——你可以在前往金澤前，先用同一張票券遊覽京都、奈良、嵐山等地，回程再從金澤直接返回關西機場。對於行程包含關西＋北陸的旅客來說，這張 Pass 的 CP 值最高。

**從東京出發：全國 JR Pass 是王道**

從東京前往金澤，最直接的方式是搭乘北陸新幹線（Tokyo↔Kanazawa，約2.5小時，單程票價約 ¥15,000）。如果你持有日本鐵路周遊券（JR Pass 全國版），即可無限次搭乘全日本的 JR 鐵路，包括北陸新幹線。

全國版 JR Pass 售價為：普通車 ¥50,000（7天）/ ¥80,000（14天）/ ¥100,000（21天）；綠色車（商務艙）則為 ¥70,000 / ¥110,000 / ¥140,000。雖然價格看似高昂，但如果你行程涵蓋東京→金澤→大阪→京都→東京（或逆時針方向），一張 Pass 就能涵蓋所有交通費，省去分段購票的麻煩。

**進階選擇：JR 關西&北陸地區鐵路周遊券**

對於行程集中在關西＋北陸的旅客，JR West 還推出「關西&北陸地區鐵路周遊券」（Kansai & Hokuriku Area Pass），售價約 ¥15,000（連續4天）。這張 Pass 的覆蓋範圍比關西廣域周遊券更廣，包含：

  • 關西機場到大阪/京都全區域
  • 大阪/京都至金澤的特急全區間
  • 富山、冰見、輪島方向的區間
  • 部分私鐵（如和歌山電鐵）

這張 Pass 適合想要深度探索北陸三縣（石川、富山、福井）的旅客，但需注意它不涵蓋東京到關西的新幹線。

**金澤市內交通：JR Pass 鞭長莫及**

抵達金澤後，市內交通主要依靠巴士或路面電車。JR Pass 無法用於金澤市內的交通，這點需要特別留意。金澤市內的推薦交通方式包括：

  • **周遊巴士一日券**（¥500）：涵蓋主要景點如兼六園、金澤城、近江町市場
  • **金澤路面電車**：單程 ¥200起，適用於市區短程移動

如果你的行程以金澤市區為主，且不打算使用 JR 新幹線或特急，那麼購買當地的一日券會比 JR Pass 更實惠。

**旅遊小提示**

1. ** JR Pass 需在出發前購買**：海外旅行社或 JR 官網預購後，抵達日本機場或車站才能兌換實體票券，切勿到日本才購買。

2. **金澤的旅遊旺季**：春季（3-5月，賞櫻兼六園）與秋季（10-11月，賞楓）是金澤最美季節，屆時關西廣域周遊券搭配金澤行程是最熱門的玩法。

3. **千萬別把 IR 石川鐵道誤當 JR**：金澤站周邊的 IR 石川鐵道營運的路線（如金澤↔七尾方向）需另外購票，JR Pass 不適用。

4. **回程規劃**：如果從金澤返回關西，強烈建議使用關西廣域周遊券，因為單程金澤→大阪的特急費用就高達 ¥5,000 以上，來回輕鬆超越 Pass 成本。

金澤這座城市融合了傳統工藝（如金箔、漆器）與現代文化創意，既有兼六園的典雅，也有 21 世紀美術館的前衛。選擇正確的 JR Pass，能讓你把更多預算留在品嚐近江町市場的海鮮料理、體驗茶屋街的懷舊氛圍上，而非交通費的過度支出。
