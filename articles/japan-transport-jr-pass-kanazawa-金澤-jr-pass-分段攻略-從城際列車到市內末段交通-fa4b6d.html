金澤 JR Pass 分段攻略：從城際列車到市內末段交通

2026-08-21 1821 字
金澤自由行 JR Pass 北陸交通

簡介

遊金澤要先釐清一件事：JR Pass 主要解決前往金澤的城際鐵路，不是市內景點通票。從東京出發，可乘北陸新幹線前往金澤，車程約2.5小時；若由京都或大阪前往，通常需要按當時列車安排轉乘。是否值得購買 Pass，不能只看「會不會去金澤」，而要計算整段旅程還包括多少次長距離 JR 移動。

這篇採用「行李與移動負擔」角度：特別適合長者同行、親子家庭、冬季旅客，以及攜帶大型行李的人。最實用的判斷方式，是把行程拆成城際 JR、金澤站轉乘、市內巴士與步行四段，再逐段確認覆蓋範圍。

特色亮點

全國版 JR Pass 的核心價值，是把東京、金澤及其他 JR 城市串成一條長距離路線。若只是東京往返金澤，未必自然代表划算；若旅程還包括多個遠距離城市，Pass 的使用價值才會提高。區域型 JR Pass 的適用範圍各異，購買前應核對有效區域、列車種類、指定席規則及使用日數。

金澤市內的兼六園、東茶屋街及近江町市場等主要景點，多數需要巴士或步行完成末段交通。市內巴士通常不屬於一般 JR Pass 覆蓋範圍，因此不能把「JR 到金澤站」理解成整天交通免費。這個盲點對長者和大型行李旅客尤其重要：少一次轉乘，有時比節省小額車資更有價值。

推薦地點

1. 金澤站、鼓門與款待圓頂

地址：〒920-0858 石川縣金澤市木之新保町1-1

金澤站本身就是行程控制中心。抵達後先處理指定席、寄存行李與巴士乘車資訊，再進市區會順暢得多。東口的鼓門結合傳統鼓架意象與現代車站設計；大型玻璃圓頂則在雨雪天提供實際遮蔽。若同行者腳力有限，建議把住宿設在車站周邊，減少拖行李乘巴士的次數。

2. 近江町市場

地址：〒920-0905 石川縣金澤市上近江町50

這裡適合作為抵達日第一站，原因不是單純「吃海鮮」，而是位置相對集中，能以較短步行完成用餐與採買。市場內各店價格、休息日及營業時間不同，海鮮丼通常會因魚種、季節與份量出現明顯價差。午間熱門時段容易排隊，拖著大型行李入內會降低移動效率，先在車站或住宿處寄存更實際。

3. 金澤城公園

地址：〒920-0937 石川縣金澤市丸之內1-1

金澤城公園適合用來理解城下町結構，石垣、城門與復原建築比單純拍照更有內容。園區範圍大，部分路面及坡度會增加輪椅、嬰兒車與長者的負擔；雨雪後亦可能濕滑。建議由較接近下一站的出入口規劃單向動線，避免在園內折返。

4. 兼六園

地址：〒920-0936 石川縣金澤市兼六町1

兼六園與金澤城相鄰，最有效率的安排是兩地連遊。庭園的特色在於池泉、坡地、橋景與季節植栽形成連續景觀，而不是隻看單一地標。冬季雪吊最具辨識度，但低溫、積雪及提早天黑會降低步行效率。園內通常需要購票，開放時間與費用可能因季節或政策調整，出發前應查閱官方公告。

5. 東茶屋街

地址：〒920-0831 石川縣金澤市東山1丁目

東茶屋街保留木造茶屋建築與狹長街道尺度，適合觀察金澤昔日茶屋文化。它的限制同樣明確：熱門時段人流集中，部分店舖空間狹窄，也不是每間歷史建築都能自由入內。最好在早段到訪，並把大型行李留在住宿處；若與兼六園排在同一天，應預留巴士候車及塞車時間。

實用資訊

交通方面，東京至金澤可利用北陸新幹線，約2.5小時。由京都、大阪或其他城市出發時，列車路線與轉乘安排可能調整，應以出發日的官方時刻表為準。到達金澤站後，主要依靠市內巴士和步行；JR Pass 通常不支付這些末段交通。

費用方面，不列固定 JR Pass 價格，因售價、產品內容與適用條件可能調整。正確做法是把所有長距離 JR 單程票合計，再與出發時官方公佈的 Pass 價格比較，同時加入指定席需求及轉乘便利性。景點門票、巴士票與餐飲費應分開編列。

各景點與市場店舖的營業時間並不一致，兼六園亦可能採季節性開放時間。行程表應把營業資料標示為「出發前複核」，不要與較穩定的地理位置和交通結構混在一起。

旅遊小提示

冬季需預留列車延誤、積雪和濕滑路面的緩衝；夏秋遇颱風，也要留意停駛及巴士調整。手機應開啟日本災害通知，並記下住宿避難路線。地震發生時不要急於衝出車站，應依站務員廣播與現場指示行動。

若帶長者或大型行李，最穩妥的行程不是一天塞滿景點，而是以金澤站寄存行李、每半天安排一個主要區域。JR Pass 負責跨城效率，市內則用少轉乘、短步行的方式設計；兩者分工清楚，才是真正適合金澤的交通攻略。

常見問題

只有東京往返金澤，購買全國版 JR Pass 一定划算嗎？

不一定。應把實際長距離 JR 票價、指定席需求及其他跨城行程合計，再與出發時的官方 Pass 價格比較；不要只憑一次金澤往返作決定。

JR Pass 可以搭乘金澤市內巴士前往兼六園嗎？

一般不能直接視為涵蓋。JR Pass 主要處理城際 JR 路段，金澤站至兼六園、東茶屋街等末段通常要另付巴士費或步行，實際適用範圍應以所購票券條款為準。
