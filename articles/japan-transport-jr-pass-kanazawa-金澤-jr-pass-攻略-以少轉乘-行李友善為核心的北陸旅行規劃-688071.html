金澤 JR Pass 攻略：以少轉乘、行李友善為核心的北陸旅行規劃

2026-08-25 1989 字
金澤JR Pass 北陸自由行 日本鐵路交通

簡介

金澤的 JR Pass，真正價值不在市內任搭，而是處理「如何抵達金澤，以及如何由金澤前往下一座城市」。金澤站是北陸重要鐵路樞紐，適合串連東京、富山、福井、京都與大阪；但兼六園、金澤城、近江町市場等核心景點，最後一段通常仍要步行或乘搭市內巴士。換句話說，JR Pass 解決城際長距離，市內交通則要另作預算。

這篇特別從長者、親子及攜帶大型行李旅客的角度規劃。判斷 Pass 是否划算，不應只問「去幾天」，而要逐段檢查：哪些路程由 JR 營運、哪些需要巴士或其他交通，以及能否減少購票與轉乘壓力。全國版 JR Pass 並非必然最省；行程集中於北陸時，區域型鐵路周遊券或單買車票可能更合適。各款票券售價、適用列車及指定席規則會調整，出發前應以官方最新條款重新計算，避免引用過時價格。

特色亮點

金澤最適合採用「鐵路進城、巴士慢遊」模式。抵達金澤站後，可把大型行李寄存在車站置物櫃或送往酒店，再以近江町市場、金澤城、兼六園及東茶屋街組成單向路線，減少拖行李上落巴士。這種安排對膝關節不適、帶幼童或冬季到訪者尤其實際。

使用 JR Pass 的另一優點是可把金澤設為北陸住宿基地，利用鐵路前往富山或福井，再返回同一間酒店，省去每日搬執行李。不過，若整趟旅程只安排東京至金澤單程，再由金澤前往京都或大阪，單買車票往往更容易控制成本。計算時應比較實際乘車區間，而非假設「有 Pass 就一定便宜」。

推薦地點

1. 金澤站、鼓門與曉之翼

地址：〒920-0858 石川縣金澤市木之新保町1-1。車站本身就是理解金澤交通的起點：新幹線、在來線、巴士總站、觀光案內所與行李設施集中於此。鼓門適合短暫拍照，但更重要的是先確認回程月臺、巴士乘車處及電梯位置。對長者而言，預留至少20至30分鐘轉乘，比排滿景點更有價值。公共區域原則上全天可通行，各商店及服務櫃檯時間不同。

2. 近江町市場

地址：〒920-0905 石川縣金澤市上近江町50。市場以海鮮、加賀蔬菜及熟食見長，適合安排在上午或午餐時段。它不是 JR Pass 景點，但由金澤站前往的末段交通很具代表性：可乘巴士或步行約15至20分鐘。餐飲預算可按店舖和季節彈性預留約¥1,500至¥4,000；海鮮價格會受漁獲影響。多數店舖約於上午營業至傍晚，餐廳各有休息日，不宜把晚餐押在市場打烊前。

3. 金澤城公園

地址：〒920-0937 石川縣金澤市丸之內1-1。石川門、五十間長屋與復原城郭展示，能看出加賀藩的防禦和建築尺度。公園部分割槽域免費，部分復原建築可能另收參觀費。一般開園時間約為早上至傍晚，季節可能調整。園內範圍大、石板路較多，雨雪天對輪椅、行李箱及步伐較慢的旅客並不輕鬆，建議只帶隨身小袋入園。

4. 兼六園

地址：〒920-0936 石川縣金澤市兼六町1。兼六園的價值在四季景觀與庭園動線，而非快速打卡。冬季雪吊、春季花景及秋色各有特色，但坡道、碎石路與濕滑路面也是實際門檻。成人入園費通常為數百日圓級，開園時間依季節變動；JR Pass 一般不包含門票。與金澤城安排在同一天，可減少巴士轉乘，但長者宜把兩處拆成半日，途中安排室內休息。

5. 東茶屋街

地址：〒920-0831 石川縣金澤市東山一丁目一帶。木造茶屋建築儲存完整，重點不是隻有拍攝街景，也可觀察金箔工藝、茶文化及金澤抹茶甜點如何融入歷史街區。街區免費，店內消費各異，甜點及飲品可預留約¥700至¥1,500。多數店舖集中在日間營業，傍晚後選擇明顯減少。石板路和人潮令大型行李非常礙事，應先寄存行李再前往。

實用資訊

由東京方向進入金澤，可利用北陸新幹線；由京都、大阪方向前往時，現行路線可能涉及在北陸區域轉乘，不能沿用過去「特急列車直達金澤」的印象。鐵路班次、轉乘站及周遊券覆蓋範圍可能改動，訂票前應核對整段營運公司與列車類別。大型行李旅客宜優先選擇較長的轉乘時間，並預先劃定指定席；不要把月臺更換、電梯排隊和洗手間時間忽略。

市內巴士、觀光迴圈路線、計程車、景點門票及餐飲通常不屬 JR Pass 覆蓋範圍。最穩妥的費用模型是「城際 JR 車票或 Pass＋市內交通＋門票」分開計算。景點常見營業時段約為09:00至17:00前後，市場偏早、茶屋街店舖偏日間，但季節、休館日及臨時安排均可能變動。

旅遊小提示

金澤雨雪較多，摺傘、防滑鞋和可防水的行李套，比多排一個景點更實用。冬季應避免把巴士接駁壓得太緊；颱風季或地震後則要檢視鐵路停駛、延誤及替代運輸資訊，手機預先啟用日本災害通知，並記下酒店與避難場所位置。

若同行者行動較慢，可採用「金澤站寄存行李—近江町市場—金澤城或兼六園二選一—計程車返回」的低負擔版本。JR Pass 是城際移動工具，不是整座金澤的通行證；把它放回正確角色，行程才會省錢，也真正省力。

常見問題

JR Pass 可以乘搭金澤市內巴士嗎？

一般不能。JR Pass 主要覆蓋符合條款的 JR 城際鐵路，金澤市內巴士、觀光循環路線、計程車及景點門票通常需要另外付費。

只去東京、金澤、京都或大阪，是否一定要買全國版 JR Pass？

不一定。應把每段實際車票、可能適用的區域型周遊券及市內交通分開比較；若乘車次數不多，單買車票可能更省。票價和適用規則會調整，出發前需按最新資料計算。
