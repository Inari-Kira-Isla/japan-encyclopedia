簡介

東京的 JR Pass 不是一張可以乘搭全市所有交通工具的萬用票。它真正的價值，在於把東京當作基地，於有效期內密集乘搭新幹線或 JR 特急列車前往外縣市。若行程主要停留在新宿、澀谷、淺草、銀座及臺場，單程購票配合 Suica 或 PASMO，通常比全國版 Japan Rail Pass 更合理。

規劃時先問三個問題：會否離開東京兩次以上、是否需要搭新幹線、長途移動是否集中在連續數天。三項多數答「是」，才值得比較全國版與 JR 東日本地區票券。票價及銷售條件會調整，不宜用舊攻略的金額直接判斷；最可靠的方法，是把預定長途車程逐段列出，再與出發時的官方售價比較。

特色亮點

JR Pass 的優勢不是讓每一程都免費，而是降低密集跨城移動的邊際成本。全國版適合東京進、關西或更遠地區出的長線行程；只遊關東、甲信越或東北，地區版往往更貼合路線。東京都內可使用山手線、中央線、京濱東北線等 JR 路線，但東京 Metro、都營地下鐵、百合海鷗號、私鐵及大部分巴士不在適用範圍內。

指定席是另一項實際價值。長者、親子旅客或攜帶大型行李者，提早劃位可減少站立與臨時轉車壓力。部分高速列車、頭等車廂、私人鐵路路段或特定最快車種可能需要附加費或不適用，訂票前必須核對票券條款。

推薦地點

1. 東京站
地址：〒100-0005 東京都千代田區丸の內1丁目
這裡是測試 JR Pass 是否合算的最佳起點。東海道、東北、上越及北陸方向的新幹線集中，亦可接駁山手線、中央線與成田特快。丸之內側建築適合觀景，八重洲側則方便轉乘高速巴士。車站面積很大，跨月臺轉乘最好預留20至30分鐘。

2. 鎌倉
地址：〒248-0006 神奈川県鎌倉市小町1丁目
從東京可乘 JR 橫須賀線直達，適合沒有新幹線需求的一日遊。小町通、鶴岡八幡宮與北鎌倉寺院群能組成步行路線，但前往長谷、大佛及江之島常用的江之電不屬 JR，需另付車資。這條路線也說明瞭：使用 JR Pass 不代表目的地內的末段交通全包。

3. 川越
地址：〒350-1122 埼玉県川越市脇田町
川越以藏造老街、時之鐘及菓子屋橫丁形成緊湊的歷史街區。從新宿一帶可利用 JR 埼京線直通川越線，但市中心景點與 JR 川越站仍有一段距離，需要步行或另搭巴士。若只安排川越一程，單買車票通常比為此啟用全國版通票划算。

4. 日光
地址：〒321-1406 栃木県日光市松原町
日光適合已有地區票券、並願意早起的旅客。JR 路線通常要經宇都宮轉乘，車程與轉車壓力高於鎌倉；回報則是世界遺產社寺、杉木參道與山區景觀。東照宮、中禪寺湖及華嚴瀑布之間依賴巴士，JR Pass 一般不能處理全部末段費用。冬季路面結冰，颱風或豪雨季也要為班次異動保留後備方案。

5. 輕井澤
地址：〒389-0102 長野県北佐久郡軽井沢町軽井沢
北陸新幹線令輕井澤成為最能體現鐵路通票價值的東京近郊目的地之一。舊輕井澤、雲場池及高原單車路線適合避暑，冬季則以滑雪和購物為主。景點分散，抵達後仍可能需要巴士、租單車或計程車；若只即日往返一次，應先比較來回指定席票價與地區票券成本。

實用資訊

東京主要 JR 電車大致由清晨5時執行至午夜前後，新幹線、指定席售票處及旅遊服務中心各有不同時間。JR Pass 通常按連續日數計算，不是按實際乘車日扣除，因此不要在純東京都內活動日過早啟用。費用方面，市內短途以逐程付款為主；跨城旅程則把新幹線、特急與指定席費用加總，再比較當期通票售價。機場交通也要分清：成田特快屬 JR 系統，但京成 Skyliner、東京單軌電車以外的私營路線及機場巴士不能一概視為涵蓋。

旅遊小提示

把所有長途 JR 行程排在同一個有效期內，是提高回本率最有效的方法。熱門週末、櫻花季、紅葉季及日本連假應提早劃位；大型行李要核對列車的預約及放置規則。手機儲存票券條款、住宿地址與離線地圖，並記下最近的避難場所。遇上地震先聽從站務員指示，不要自行進入路軌；颱風接近時，新幹線可能預防性停駛，行程應預留一日緩衝，而不是把最後一班長途列車接國際航班。
