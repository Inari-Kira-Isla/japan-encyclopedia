簡介

到金澤使用 JR Pass，真正要解決的是「如何抵達金澤」，而不是市內無限乘車。金澤站是北陸新幹線的重要樞紐，從東京可乘北陸新幹線直達；由京都或大阪出發，通常要先乘 JR 特急到敦賀，再轉北陸新幹線前往金澤。持全國版或地區版 JR Pass 是否划算，應按整段行程逐一核對，而不是隻看金澤單程票價。

這篇特別適合帶長者、嬰兒車或大型行李的旅客。金澤景點集中，但多數末段交通依賴市內巴士或步行，JR Pass 通常不能包辦；若下雨、下雪或遇上巴士擁擠，省下的車票費可能不及少轉一次車重要。

特色亮點

金澤最適合納入「東京進、關西出」或反方向的跨城路線。JR Pass 的價值來自東京、長野、富山、金澤、敦賀及關西之間的長距離移動；只安排金澤兩三天、市內觀光為主，單買車票往往更直接。

規劃時可做一次覆蓋率審計：把行程拆成城際 JR、金澤站轉乘、市內巴士及景點步行四段。只有第一段穩定屬於 JR 鐵路範圍；指定席、可乘列車及地區版 Pass 的有效區間則須按票種確認。大型行李旅客應預留敦賀轉乘時間，不要安排過緊的同月臺假設。

推薦地點

1. 兼六園
地址：〒920-0936 石川県金沢市兼六町1
金澤代表性庭園，曲水、石橋、松樹與高低地形共同構成景觀。冬季雪吊最有辨識度，但石路在雨雪後可能濕滑；帶長者時宜從較平緩入口進入，並減少與金澤城來回爬坡。一般開園約由清晨至傍晚，季節不同會調整；入園通常需付費。

2. 金澤城公園
地址：〒920-0937 石川県金沢市丸の內1-1
適合與兼六園排成同一區，但園區尺度比地圖看起來更大。菱櫓、五十間長屋及復原城郭展示，能看懂加賀藩的防禦與木造建築技術。公園部分割槽域通常免費開放，個別展示設施可能收費並有獨立時間。

3. 金澤21世紀美術館
地址：〒920-8509 石川県金沢市広坂1-2-1
圓形建築沒有明顯正門，動線比傳統美術館自由，適合在兼六園後作室內避雨站。交流區與收費展覽區並不相同，熱門作品亦可能需要預約或整理券。一般日間開放，展覽、休館日及費用依企劃變動。

4. 近江町市場
地址：〒920-0905 石川県金沢市上近江町50
市場強項是海鮮、加賀蔬菜與即食小吃，不只是觀光海鮮丼集中地。鮮魚價格會受季節、天候及運輸成本影響，空運燃油附加費上升時，部分遠距海產尤其容易調價。想避開人潮可在午餐尖峰前到達；多數店舖由早上營業至下午，但各店休息日不同。

實用資訊

東京方向以北陸新幹線最省轉乘；京都、大阪方向一般經敦賀轉車。JR Pass 不宜只問「能否去金澤」，還要確認所持票種是否涵蓋出發站、列車、指定席與全段路線。Pass 價格及規則可能調整，購買前應以當期官方資料比較「實際長途車票總額」與 Pass 售價。

抵達金澤站後，兼六園、金澤城、近江町市場及美術館主要靠巴士、計程車或步行。市內巴士一日券及單次車資不應預設包含於 JR Pass。四人同行、帶長者或雨雪天，短程計程車有時比多次轉乘更有效率。景點費用大致由免費區域至數百日圓，特別展另計；營業時間與休館日應在出發前再次確認。

旅遊小提示

住宿選金澤站附近，優點是拖行李及跨城移動容易；若重視早晨散步與夜間街景，香林坊、廣坂一帶更接近主要景點，但到站後仍要轉巴士。金澤雨天較多，鞋底防滑比多帶一件漂亮外套實際。冬季應為列車延誤和結冰預留彈性，颱風季亦不要安排當晚必須銜接國際航班的緊迫行程。遇地震或強風停駛時，先檢視車站公告、確認避難位置，並準備少量現金、飲用水及行動電源。
