神戶 JR Pass 實戰指南：以新神戶為樞紐的山海一日遊

2026-08-14 1760 字
神戶自由行 JR Pass 關西交通

簡介

神戶最適合把 JR Pass 當作「跨城移動工具」，而不是市內交通萬用券。若行程包含大阪、姬路、岡山或廣島，JR 西日本地區周遊券或全國版 JR Pass 才可能發揮價值；只在神戶市區活動，逐程使用 ICOCA，通常更簡單。判斷方法很直接：先把新幹線與跨城 JR 車資相加，再與出發時適用的通票售價比較，切勿因為名稱有 Pass 就預設一定省錢。

另一個常見誤區，是把「新神戶站」和「三宮站」視為同一個交通中心。新神戶主要服務山陽新幹線，三宮才是 JR 神戶線、阪急、阪神、地下鐵及巴士集中的市區樞紐。兩站之間不是 JR 路段，需乘神戶市營地下鐵或巴士，因此即使持有 JR Pass，也可能另付市內交通費。

特色亮點

神戶的優勢不是景點全部緊貼 JR 車站，而是能把山、港口、洋館與溫泉串成層次分明的行程。持合適通票的旅客，可早上由大阪或京都抵達神戶，下午延伸至姬路；若以新神戶為住宿基地，更能利用山陽新幹線向岡山、廣島移動。相較把每天時間耗在大阪往返，這種「神戶住一晚、東西兩向放射」的安排更適合重視效率的鐵道旅行者。

推薦地點

1. 布引香草園／纜車

地址：〒650-0002 兵庫県神戸市中央區北野町1-4-3。入口靠近新神戶站，最適合新幹線抵達後直接上山，不必先拖行李到港區。纜車沿途可俯瞰神戶市街與大阪灣；園內不是單純花圃，還有溫室、香草展示及步道。JR Pass 不涵蓋纜車，來回票通常屬¥2,000級別，應列入額外預算。

2. 北野異人館街

地址：〒650-0002 兵庫県神戸市中央區北野町。這一帶儲存神戶開港後形成的西式住宅群，坡道、石階與洋館共同呈現港都國際化歷史。由新神戶或三宮步行可達，但坡度明顯；與其購買多館套票後趕場，更建議挑一至兩座真正感興趣的館舍，其餘時間觀察街區建築。

3. 神戶港震災紀念公園及美利堅公園

地址：〒650-0042 兵庫県神戸市中央區波止場町2。保留下來的受災碼頭，能直接看見1995年阪神淡路大地震對港灣設施造成的破壞。旁邊是開闊海濱、公園與港區地標，適合黃昏散步。景點免費、全天開放，但最近的交通多為地下鐵或步行，並非持 JR Pass 就能直達。

4. 舞子公園與橋之科學館

地址：〒655-0047 兵庫県神戸市垂水區東舞子町2051。從 JR 舞子站步行即達，是神戶少數能充分利用 JR 市內移動的海景點。近距離觀看明石海峽大橋，比只在港區拍照更有工程尺度感；館內則介紹吊橋結構、施工技術及海峽交通。公園免費，展示設施與海上步道另行收費，適合建築迷或親子旅客。

5. 有馬溫泉

地址：〒651-1401 兵庫県神戸市北區有馬町。有馬以含鐵鹽泉「金泉」及透明「銀泉」聞名，適合放在神戶行程末段泡湯。然而前往有馬主要依靠神戶電鐵、地下鐵或巴士，通常不屬 JR Pass 核心覆蓋範圍。若只為用盡通票而放棄有馬，反而本末倒置；旅程體驗比形式上的全程免費更重要。

實用資訊

新大阪至新神戶可乘山陽新幹線，車程約十多分鐘；大阪站至三之宮站則可乘 JR 神戶線新快速，約半小時。由京都出發，若不必追求最快速度，JR 新快速可直接抵達三之宮；由神戶向西，JR 舞子、明石及姬路很容易串聯。注意全國版 JR Pass 一般不能搭乘希望號與瑞穗號，實際可乘列車及指定席規則應以手上通票條款為準。

景點費用大致從免費公園、數百日圓級博物館，到¥2,000級別纜車或套票不等。多數展示館約於09:00至17:00營業，纜車、洋館及科學館會因季節、休館日或維修調整；JR Pass 價格亦會變動，購買前應核對官方最新資料。

旅遊小提示

若只有「大阪—神戶往返＋神戶市內」一天，不買 JR Pass 往往更合理；若連續前往姬路、岡山或廣島，地區型通票才進入值得計算的範圍。住宿靠三宮適合吃飯與市內轉乘，靠新神戶則適合頻繁搭新幹線，兩者服務的是不同旅客。

神戶坡道多，北野與布引安排在體力較好的上午，港區放在傍晚最順。準備 ICOCA 支付非 JR 路段，並預留少量現金。日本地震或颱風可能造成列車停駛；出發前確認列車執行資訊、住宿避難路線與最近避難場所，手機亦應開啟災害通知。遇到強震時先遠離玻璃及招牌，港邊旅客需留意海嘯警報並依指示往高處移動。
