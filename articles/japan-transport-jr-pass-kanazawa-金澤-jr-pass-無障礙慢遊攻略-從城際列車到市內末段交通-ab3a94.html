金澤 JR Pass 無障礙慢遊攻略：從城際列車到市內末段交通

2026-08-25 1761 字
金澤自由行 JR Pass 北陸交通

簡介

遊金澤是否需要 JR Pass，關鍵不在「會不會搭 JR」，而在金澤以外還安排了多少長途移動。金澤站是北陸的重要鐵路門戶，JR Pass 主要用來處理前往金澤的城際 JR 路段；抵達後，兼六園、近江町市場與主要文化區多靠巴士、步行或計程車，通常不能直接使用 JR Pass。

自北陸新幹線延伸至敦賀後，京都、大阪方向前往金澤一般須在敦賀轉乘。對長者、親子家庭及攜帶大型行李者而言，Pass 是否划算只是第二層問題；月臺距離、轉乘時間、指定席與行李處理才真正影響旅程品質。最實用的判斷方式，是把行程逐段列出，分成「JR 可覆蓋」、「巴士或其他鐵路」、「步行與計程車」，再比較合適的全國版或地區型周遊券，而不是隻看單程票價。

特色亮點

金澤適合採用「鐵路進城、巴士慢遊」模式。東京方向可利用北陸新幹線抵達金澤；關西方向則要留意敦賀轉乘。若行程還包括富山、福井或其他 JR 沿線城市，周遊券的價值通常較高；若只從東京往返金澤一次並在市內停留數天，單買車票可能更直接。

金澤站設有升降機、寄物櫃及旅客服務設施，但賞櫻、紅葉、週末與連假期間，大型寄物櫃可能很快滿額。住宿旅客可優先把行李寄往酒店；即日遊則應先寄存行李，避免拖著行李登上市內巴士。這個安排通常比省下一小段車資更有價值。

推薦地點

1. 金澤站、鼓門與玻璃雨傘「款待圓頂」

地址：〒920-0858 石川縣金澤市木之新保町1-1。鼓門就在東口，是理解金澤交通佈局的起點。站內可先確認回程月臺、巴士乘車處及寄物位置；遇上北陸雨雪，也能利用有遮蔽的空間整理行李。建議預留30至45分鐘，不要把它只當成拍照後立即離開的車站。

2. 近江町市場

地址：〒920-0905 石川縣金澤市上近江町50。由金澤站前往較適合搭巴士或計程車，JR Pass 通常派不上用場。市場的強項是海鮮、加賀蔬菜與即食小吃集中，缺點是熱門海鮮丼店午市排隊明顯。想減少久站，可在上午較早時段到訪；餐費由約¥1,000的小食、簡餐至¥3,000以上的海鮮料理都有。

3. 兼六園

地址：〒920-0936 石川縣金澤市兼六町1。兼六園的價值在四季景觀與精細庭園動線，不只是「日本三名園」頭銜。園內有坡道、砂礫路及高低差，長者宜穿防滑鞋並縮短遊覽範圍。一般成人入園費約¥320，開園時間會隨季節調整；可把兼六園與金澤城安排在同一區，減少重複乘車。

4. 金澤城公園

地址：〒920-0937 石川縣金澤市丸之內1-1。石川門、復原城郭建築與寬闊草地，適合用來理解加賀藩的城市尺度。公園大部分割槽域可自由進入，部分復原建築另行收費，常見成人票約¥320。園區面積不小，若同行者膝腳不便，不必勉強繞完整圈，可從兼六園側進入後集中參觀主要建築。

5. 金澤21世紀美術館

地址：〒920-8509 石川縣金澤市廣坂1-2-1。館舍採圓形設計，公共區域與收費展區分開，適合依體力彈性調整。展覽票價及開放安排因企劃而異，熱門作品也可能需要整理券或等候。它與兼六園距離近，安排在同一天可降低市內交通成本；附近亦容易找到抹茶甜點，適合作為步行行程的休息點。

實用資訊

東京方向可搭北陸新幹線前往金澤；京都或大阪方向通常經特急列車至敦賀，再轉北陸新幹線。使用 JR Pass 前，應核對所選列車、座席種類及完整路段是否受券種覆蓋，並以購買當日官方條款和票價為準。全國版及地區型 Pass 價格可能調整，本文不列固定售價。

金澤市內主要依靠路線巴士、觀光迴圈巴士、步行及計程車。單次巴士車資通常只需數百日圓，但多數 JR Pass 不包含這些末段交通。景點普遍約09:00起開放、17:00前後關閉，但季節、展覽、休館日及最後入場時間各異；市場店舖則多在上午至下午營業，傍晚選擇會明顯減少。

旅遊小提示

冬季與雨天不要把轉乘壓在數分鐘內，北陸天候可能影響列車與步行速度。大型行李旅客宜預約指定席，並按列車規則處理超大行李。地震或颱風期間，先檢視車站公告、住宿疏散路線及地方避難資訊，手機保留離線地圖與緊急聯絡資料。若只遊金澤市中心，巴士一日券或按次付款往往比為了「用盡 JR Pass」而繞路更合理；真正高效率的玩法，是讓 JR Pass 負責跨城，把市內時間留給步行、休息與文化體驗。

常見問題

只從東京往返金澤，購買 JR Pass 一定比較便宜嗎？

不一定。應按實際日期比較往返車票與 Pass 售價，並計算是否還有富山、福井等其他長途 JR 行程。若主要活動都在金澤市內，Pass 的可用範圍有限。

JR Pass 可以搭金澤市內觀光巴士嗎？

一般不能。JR Pass 主要覆蓋符合條款的 JR 鐵路路段，市內路線巴士、觀光循環巴士與計程車通常需要另行付費。
