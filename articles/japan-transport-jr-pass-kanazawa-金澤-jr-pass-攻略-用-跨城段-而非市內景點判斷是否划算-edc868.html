金澤 JR Pass 攻略：用「跨城段」而非市內景點判斷是否划算

2026-08-16 1628 字
金澤交通 JR Pass 北陸自由行

簡介

金澤沒有名為「Kanazawa JR Pass」的專屬通票。規劃金澤交通時，真正要問的不是「買哪張金澤 Pass」，而是行程是否包含東京、長野、富山、福井、京都或大阪等跨城移動。金澤市內主要景點集中，最後一段多靠巴士或步行，JR Pass 通常無法全程覆蓋。因此，這篇以「帶父母或大件行李、重視少轉車」的旅客為核心：把 JR 通票留給昂貴的城際列車，市區另付巴士費，往往比硬追求全程免費更省心。

特色亮點

金澤是北陸新幹線的重要樞紐，適合串連東京、長野及富山；前往福井方向亦可利用新幹線與其他 JR 列車。若從關西出發，現行路線通常涉及敦賀轉乘，持有通票不代表可以避免換車。

可考慮的型別包括全國版 Japan Rail Pass、連線東京與關西並經北陸的 Hokuriku Arch Pass，以及 JR 西日本部分北陸區域票券。是否值得買，要逐段核對指定席、列車種類和使用日期，而非只看「有 JR」三個字。金澤站至兼六園、東茶屋街及近江町市場常用的市內巴士，一般不屬於 JR 鐵路通票核心覆蓋範圍；私鐵、地方鐵道和部分巴士亦須另外購票。

推薦地點

1. 金澤站、鼓門與玻璃穹頂

地址：〒920-0858 石川県金沢市木ノ新保町1-1。這裡不只是抵達點，也是檢查行程效率的最佳位置。鼓門與「款待圓頂」適合抵達後直接拍攝；旅遊服務設施、寄物櫃與巴士乘車區集中，帶長輩或行李時可先在站內完成寄存，再輕裝進城。

2. 近江町市場

地址：〒920-0905 石川県金沢市上近江町50。市場以北陸海產、壽司、海鮮丼及加賀蔬菜見長。它距金澤站不算遠，適合作為抵達日第一站。熱門店午間可能排隊，海鮮價格亦會受季節、漁獲與航空冷鏈成本影響，不宜把網路舊選單當作固定價格。

3. 金澤城公園與兼六園

兼六園地址：〒920-0936 石川県金沢市兼六町1。兩處相鄰，可合併安排半天，減少巴士上下車次數。兼六園的池泉、曲水、石燈籠及冬季雪吊呈現不同季節景觀；金澤城則可觀察石垣、城門與復原建築。這組合最能體現金澤不是單純美食城市，而是加賀藩歷史與庭園美學的核心。

4. 金澤21世紀美術館

地址：〒920-8509 石川県金沢市広坂1-2-1。圓形建築與多方向入口降低傳統美術館的距離感，部分公共區域可自由進入，特展則另行收費。它就在兼六園附近，適合排在同一天；熱門作品可能採預約或限制入場，不能只憑 JR 通票臨時決定。

5. 東茶屋街

地址：〒920-0831 石川県金沢市東山1丁目一帶。木造茶屋建築、金箔工藝與和菓子店集中，特色是儲存完整的街區尺度，而非單一打卡建築。抹茶甜點適合作為散步休息，但主街午後人潮較密；想拍到安靜街景，可在店舖全面營業前抵達，同時注意住宅範圍與私人出入口。

實用資訊

由東京前往金澤，可搭北陸新幹線；由京都或大阪出發，通常經敦賀轉乘。是否能乘坐指定列車及預約指定席，須依所購票券條款確認。JR Pass 價格會調整，本文不列固定金額；購買前應把實際行程逐段查價，再與通票售價比較。若只停留金澤一至兩天、沒有長距離 JR 行程，單買車票通常更直接。

市區景點多由金澤站東口巴士區出發，也可把近江町市場、金澤城、兼六園、美術館串成步行加短程巴士路線。兼六園通常需購票，金澤城公園部分割槽域免費，美術館特展另計。各設施營業時間、休館日及冬季安排不同，出發前應查閱當日公告；市場店家多在早上至下午營業，晚間選擇較少。

旅遊小提示

最實用的判斷線是：東京進、關西出或反向移動，可研究北陸相關通票；只走大阪—金澤來回，應比較單程票與區域票；只玩金澤市區，別為了「Pass」二字多買一張鐵路券。冬季需預留風雪造成的列車延誤時間，夏秋颱風期間避免安排無緩衝的轉乘。日本地震發生時，先聽從車站與設施廣播，不要急著自行離站；手機可預先開啟災害通知，並把護照、藥物和行動電源放在隨身包。這些準備比把每一段交通都塞進通票更重要。
